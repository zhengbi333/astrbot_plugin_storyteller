> **本插件由 AI 制作**（DeepSeek 与 DSH 协同开发，作者署名：证毕＆deepseek）。

>
> **这只是一个学生的尝试，技艺不精，还请海涵。** 欢迎指出问题或提供建议，我会尽力改进。

面向 AstrBot 的**拟人陪伴插件**：让 Bot 有自己的状态、情绪、日程、穿搭、衣柜、梦境与日记，记得和每个人的关系，用拟人的方式说话、沉默、发表情包，甚至主动找你聊天。

- 插件名：`astrbot_plugin_storyteller`
- 中文名：为你续写的故事
- 版本：`alpha-0.188`
- 兼容：AstrBot `>= 4.22.0`
- 编码：UTF-8

## 安装

**方式一：本地放置**（推荐）

1. 将整个插件目录（**目录名保持 `astrbot_plugin_storyteller` 不变**）放入 AstrBot 插件目录：
   ```text
   <astrbot_data>/data/plugins/astrbot_plugin_storyteller
   ```
   常见路径示例：`<astrbot 安装目录>/data/plugins/astrbot_plugin_storyteller`
2. 打开 AstrBot 管理面板 →「插件」→ 找到「为你续写的故事」→ **启用 / 重载**；
3. 打开插件 WebUI 配置各模块：基础可先用默认值；在「模型」页配置回复/生成模型（或留空回退模型），其它模块的设置修改即自动保存。

**方式二：Git 安装**：AstrBot 插件市场支持通过 Git 仓库安装，直接添加：

```text
https://github.com/xiaoxue00123/astrbot_plugin_storyteller
```

**快速开始**：
- **模型**：到「模型」页配置「留空回退模型」（或为各模块指定模型），接管/生成才可用；未配置时接管失败自动放行主链，Bot 不会没反应；
- **生图**（可选）：生图页配置独立 API（base_url / API Key / 模型）或选择卡片模式，并可在对话中以「帮我画一只猫」「拍个照发我」等触发；
- **防抖/主动对话**：默认关闭或低配置，按需在对应页开启；
- **表情包**：需要先从表情包页建分类并上传图片，否则不会乱发表情。

## 拟人核心

- **防认错**：区分当前对话对象（账号 ID 为准、换昵称仍是同一人、自称别人不轻信、对陌生人不套近乎）；称呼从联动记忆插件取。
- **关系模型**：好感度 + 关系阶段（陌生/普通/熟络/亲近）+ 互动档位，随互动自然演进（LLM 判断情感质量），带阻尼与印象提炼。
- **情绪/状态**：调子/转速/电量三维 + 心情 + 心事 + 互动涟漪 + 最近余波；事件"染色"与节拍"冲刷"均为纯函数；状态锚只注入语气不暴露数值。
- **风格锚**：七维说话风格（语气/句长/口头禅带频率与语境/标点/称呼/节奏/话量）；支持按人格一键生成。
- **日程与穿搭**：LLM 结合记忆/人格/天气/衣柜生成一天完整日程与穿搭；未来规划、延误日程两个缓存池；对话中明确安排可实时调整（替换/新增/进延误池/改穿搭）。
- **回复链路**：消息防抖（智能判定/自适应窗口）→ 主链拦截（监视/放行/阻断/接管改换/接管走主链）→ 润色 → 智能判定（沉默/草草/表情包/正常）→ 发送；接管改换支持按句拆条发送与「被抢话」裁决；回复内容自动拍平（无换行空隙）。
- **主动对话**：由状态/日程/记忆约定/见闻/梦取材，由头引擎（成熟/时段配额/去重）→ 关系适配 → 两级裁决 → 边界闸门（静默/上限/免打扰/刚聊完/未回应降速）→ 发送与回填；发送失败不消耗由头。
- **内心世界**：梦境（一夜一条长梦、余波归类）、思考（事件驱动+每日限次）、见闻（自主浏览）、日记（深夜自动）；全部内容可手动生成、页内预览。
- **图片与生图**：识图/文档/链接会意（含动图抽帧、分块全读）；生图意图三分层——硬信号直画、上下文主题锚定（"聊云→给我看看"画云）、疑问式弱信号打「{生图意愿}」软标记交给对话 LLM 自行提议；画面主题优先，人设仅人物场景参考。
- **表情包**：本地图库（分类/上传/预览/删除）、惯用组频率加权、反馈学习、用户「别发表情包」停用。
- **Token 统计**：三来源（本插件直连 / 主链 / 记忆插件）独立记账，总/当天/当月/每任务/最近明细。
- **清障页**：32 项模块自检（配置/数据/模型/平台连接），零 token 只读探测 + 可选一键 LLM 测试。

## 与记忆插件「为你篆刻的历史」的联动

- **托管注入**：放行/接管走主链时由本插件注入记忆（记忆插件自动注入跳过，避免双份）；监视/阻断/命令时恢复其自动注入。
- **写入**：约定/愿望（规则预筛→LLM 提炼→`promise` 型记忆）、用户画像（节流提炼去重）、时间线回填（接管/缓冲/主动消息实时同步）。
- **读取**：`{记忆}` 注入包、防抖智能判定上下文、主动对话素材（仅约定类）、记忆页只读展示、Token 页记忆插件消耗。
- **注意事项**：开启本插件消息拟人化托管时，请将记忆插件群聊捕获设为 `off`。

## WebUI（24 个选项卡）

总览 / 清障 / 模型 / 生图 / 外观 / 拦＆改 / 发送 / 润色 / 防抖 / 防认错 / 关系 / 风格 / 人格 / 状态 / 日程 / 穿搭 / 内心 / 记忆 / 主动 / 表情包 / Token / 设置 / 调试 / 鸣谢。

全部设置修改即自动保存；顶部选项卡支持拖拽排序；8 套主题 × 明暗 + 背景图。

## 数据

运行数据位于 AstrBot 插件数据目录 `astrbot_plugin_storyteller/`（`appearance.json`、`presence.json`、`schedule.json`、`wardrobe.json`、`mind.json`、`diary.json`、`relationships.json`、`voice.json`、`persona_injection.json`、`token.json`、`ui.json`、`emojis/`、`image_gen/`、`backgrounds/` 等），与代码分离，更新插件不清数据。
