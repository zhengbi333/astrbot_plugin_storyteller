# 为你续写的故事

`astrbot_plugin_storyteller`（中文名：**为你续写的故事**）是面向 AstrBot 的**拟人陪伴插件**：让 Bot 有自己的状态、情绪、日程、穿搭、衣柜、梦境与日记，记得和每个人的关系，用拟人的方式说话、沉默、发表情包，甚至主动找你聊天。

- 版本：`alpha-0.238`
- AstrBot 版本：`>= 4.22.0`
- 更新日志：见 [changelogs/](changelogs/)（每个版本一个 Markdown 文件）

## 安装

将插件目录放入 AstrBot 插件目录，目录名保持：

```text
astrbot_plugin_storyteller
```

运行数据默认位于 AstrBot 插件数据目录下的 `astrbot_plugin_storyteller/`（与代码分离，更新不清数据）：

```text
appearance.json / presence.json / schedule.json / wardrobe.json
diary.json / mind.json / relationships.json / token.json / voice.json
persona_injection.json / ui.json / emoji_categories.json
backgrounds/ / emojis/
```

## 拟人核心

- **防认错**：区分当前对话对象（{当前用户}/{场合}/{身份}），提醒别搞混人称——账号为准、换昵称仍是同一人、自称别人不轻信、对陌生人不套近乎；称呼从【为你篆刻的历史】插件取。
- **关系模型**：好感度 + 关系阶段（陌生/普通/熟络/亲近）+ 互动档位，随互动自然演进（LLM 判断情感质量）。
- **情绪模型**：愉悦度/唤醒度/精力量化维度 + 自然衰减 + 情绪事件即时微调。
- **风格锚**：六维度说话风格（语气/句长/口头禅/标点/称呼/节奏），口头禅带频率与语境。
- **日程与穿搭**：LLM 结合记忆/人格/天气/衣柜生成一天完整日程与穿搭；未来规划、延误日程两个缓存池。
- **回复链路**：主链回复二次润色 → 智能判定（沉默/草草回复/表情包）→ 渲染发送。
- **主动对话**：由状态/日程/记忆约定愿望/见闻/梦（含梦余波）取材，由头引擎在「好时机（时段配额+时间窗+新鲜度）」挑一条，两级裁决（值不值得说→自然表达）+ 未回应降速 + 刚聊完顺延 + 关系适配，克制日志可追溯；页内含试发预览。目标用户可填完整 UMO（含平台前缀），或填 ID（按「会话平台前缀」拼装，默认 aiocqhttp，Telethon 等请改前缀）。
- **内心世界**：梦境、思考、见闻、日记，深夜自动整理。
- **记忆联动**：与「为你篆刻的历史」联动——托管注入、写入约定/愿望、提炼用户画像。
- **图片识图**：直连识图模型，智能转述（表情包只说明情绪）后注入。
- **表情包**：本地图库 + 自定义分类 + 语境匹配发送。

## WebUI（21 个主选项卡）

总览 / 清障 / 外观 / 拦＆改 / 发送 / 润色 / 防抖 / 防认错 / 关系 / 风格 / 人格 / 状态 / 日程 / 穿搭 / 内心 / 记忆 / 主动 / 表情包 / Token / 设置 / 调试。

「总览」页除品牌信息外，展示 Bot 当前状态（心情标签、调子/转速/电量、此刻在做的事）与本插件 + 联动记忆插件的 Token 总消耗（累计）。

「清障」页（总览之后）提供 **32 项模块自检**：基础 16 项（配置加载 / 数据目录 / Token 记账 / 界面布局 / 外观 / 状态 / 日程 / 表情包图库 / 发送缓冲 / 关系档案 / 风格·人格 / 内心世界 / 记忆联动 / 模型配置 / 后台任务 / 日志系统）+ **14 个「模块名 · LLM」**（每个模块探测自己配置的全部功能模型的接口可达 / Key 有效 / 模型存在，内心含梦境·思考·日记·搜索四键、记忆含画像·约定两键）+ **「回退模型 · LLM」**（探测留空回退模型）+ **「下游客户端」**（NapCat 等消息平台适配器的官方连接状态）；全部为零 token 探测（HTTP /models 或 TCP 连接检测，不发起对话生成）；每项一个测试按钮，结果块通过 = 绿色侧边线 + 「功能正常」+ 检测详情，异常 = 红色侧边线 + 故障原因，顶部「一键全部测试」按钮与汇总。嵌入/重排模型下拉使用 AstrBot 的嵌入/重排分类列表（与 LLM 对话模型分开）。

「发送」页管理回复发送缓冲与「被抢话」裁决（仅接管改换链路承载）：接管回复按自然句段拆入缓存逐条发送（间隔按字数节奏）；用户抢话时由裁决模型判定 A 说完再回 / B 憋回去重新组织（被判 B 时没说完的话注入下一轮生成）；待发送队列与裁决记录均分页展示（每页 5 条）。

「记忆」页展示与【为你篆刻的历史】的联动状态（未安装 / 桥接未开启 / 联动正常可一键检测）、最近记忆与时间线（只读），同页管理记忆联动设置（托管注入、约定提取、画像采集与对应模型）。

「拦＆改」页管理主链对话请求的介入方式（监视 / 放行 / 阻断 / 接管改换），左侧为拦截设置与拦截记录（原「设置 → 拦截」与调试页拦截子页迁入），右侧为「最终发送给对话 LLM 的信息格式」可编辑模板（占位符 {当前说话} {上下文} {当前用户} {场合} {身份} {关系} {风格} {状态} {日程} {记忆} {天气} {见闻} {时间} 点击即插，接管改换时替换为各模块当前内容，由插件直连接管模型统一整合发送；接管模式默认开启，且 Bot 回复会自动回填【为你篆刻的历史】时间线）与「最近发送给对话 LLM 的内容」实时面板。

各功能的模型设置已迁入**所属模块页内**（统一下拉菜单展示板）：状态/日程/穿搭/内心/主动页内各自模块的模型与参数小节；润色、识图在对应模块页；搜索与记忆设置在内心页/拦＆改页；设置页仅剩「模型配置」子选项卡，管理全局生成策略（流式/单次限时/思考开关/长度预算/留空回退模型——模块模型留空回退到回退模型，回退为空则驳回请求并输出报错日志）。Token 页按来源独立展示（AstrBot 主链 / 记忆插件 / 为你续写的故事）总/当天/当月/每任务（含调用次数）/最近调用明细；提供方返回真实用量时记真实值，否则按文本估算（不额外调 LLM）。全部修改自动保存。

## LLM 工具

- `get_schedule`：检索当天日程、未来规划与延误事项。
- `set_schedule`：改写某时段日程（原计划自动入延误池并标注）。
- `add_future_plan`：记入未来规划。
- `get_outfit` / `set_outfit`：读取/修改当前穿搭与衣柜。
- `deepmem_recall` / `deepmem_remember`（联动【为你篆刻的历史】插件）。
