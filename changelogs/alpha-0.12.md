# alpha-0.12（2026-08-08）

## 变更

- **背景图压缩**（修复超大图导致的问题）：
  - 上传的图片最大边缩至 1600px；含透明通道存 PNG、不透明转 JPEG（quality 85）；
  - 此前 4.3MB 图片会以 5.8MB base64 的形式每次随外观接口全量传输，拖慢面板且可能影响渲染；
  - 压缩后 data URL 通常只有几十 KB，接口与渲染均轻快。
- **修复背景图预览不显示**：
  - 根因：预览容器内联样式 `background-image:url("data:...")` 中，data URL 两侧的双引号会提前终止 HTML 属性，样式解析失败；
  - 修复：改为单引号包裹 `url('data:...')`，并将预览容器样式拆分为独立背景属性（底色/图片/位置/尺寸），避免简写覆盖。
- **字段名对齐**：背景图透明度/模糊读取 `canvas_opacity`/`canvas_blur`（此前误读 `bg_opacity`/`bg_blur`，虽有兜底但语义错误）。
- 页面资源版本参数升至 `?v=0.12`。

## 说明

- 已上传的旧背景图（4.3MB）在重新上传前仍会原样返回；重新上传一次即可获得压缩版本。
- 版本备份：工作区 backup 目录下的 `astrbot_plugin_storyteller_alpha-0.12`。
