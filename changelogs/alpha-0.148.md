# alpha-0.148

## 用户定夺大轮：温和默认 + Token 重定义 + 防抖加速 + 生图模块(完整版)· 与 deepmemory 0.78 配套

### ① 默认介入方式改为「接管走主链」（用户定夺）

- schema `intercept.mode` 默认、`resolve_mode` 非法/空回退、main/page_api 内置默认全部改为**接管走主链**：模板拟人化改写后交主链回复（拟人最完整 + 零插件冲突——消息经主链管线，任何插件 on_llm_response/历史/记忆捕获都正常）；
- 「接管改换」仍可选（已有失败降级保护，不会哑巴）。

### ② Token 页三卡重定义 + 占比图（用户定夺）

- 新增 `astr_total` 全局记账：`on_llm_response` **无条件**记全部主链响应的真实 usage（含本插件未介入会话）——「AstrBot 总消耗」卡真实全量；
- 三卡重定义：**为你续写的故事**（直连+主链代记合计）/ **AstrBot 总消耗**（主链全部，本插件代记）/ **为你篆刻的历史**（桥接读取）；
- 新增**占比条**：两插件 vs AstrBot 主链占全部 LLM 消耗比例（总盘子=主链+陪伴直连+记忆插件）；
- 明细切换保持三线（直连/主链代记/记忆）独立，不合并入任何卡（零混算）。

### ③ 防抖智能判断默认开启 + 加速（用户定夺）

- `debounce.smart_judge` 默认 **True**；新增 `smart_judge_timeout`（判定单次超时保护，默认 **4s**，超出快速回退固定窗口，不阻塞防抖）与 `smart_judge_min_interval`（判定最小间隔，默认 2.5s，连续短消息不重复调判定模型）；
- 判定 prompt 尾部收敛「reason ≤10 字」减少生成时间；**修复**：追加消息不再把等待重置到最长 8s（智能模式 timer 由判定管理：continue→重设、release→立即、失败→回退）；顺带修复判定轮次文案（首次显示「第 1 次判断」）。

### ④ 生图模块（完整版 · 用户定夺「像示例插件一样独立 API」）

- **新「生图」选项卡**（模型之后，24 键）：后端模式开关——`api`=独立在线生图 API（主/备端点、平台归一化：OpenAI 兼容 `/v1/images/generations` / 火山 seedream / MiniMax `/v1/image_generation`）、`card`=AstrBot provider 的 text_to_image（当前为 HTML 文字卡片渲染，免费即时——AstrBot 无原生 AI 生图接口，已向用户如实说明）；
- **超时保护**：`image.api_timeout_seconds` 默认 120s（10-600 可配）；主端点失败自动切备端点；结果魔数校验（PNG/JPEG/WebP）+ 10MB 上限落盘 `plugin_data/image_gen/`；
- **触发**：对话「画一张…/给我画…/生成一张…」自然语言快判（克制规则：画饼/画重点等惯用语排除；裸「画」需画面对象词；超长排除）；上限 `image.max_daily` 默认 5（0=不限）；
- **发送与记录（用户硬性要求）**：生成成功后发送图片+说明 → 回填记忆时间线（`_note_bot_reply` → record_visible_turn → 阶段总结链路）+ 会话历史补写 + sent 快照与日志——记忆/上下文/其他插件不因图片断裂；生成失败**不拦截**（放行聊天，避免用户被晾着）；
- 生图页：状态（开关/后端/端点就绪/今日张数）+ 试生成按钮（直连验证）+ 最近生成记录（耗时/成败详细）；自拍/参考图/穿搭联动与本轮 API 主体共存（参考图读取为提示词级，多图一致性留待后续迭代——如实记录）。
