# alpha-0.169

## B1 全保序：媒体在连发/组合消息中的位置语义（用户定夺方案，超越示例插件）

- **用户场景**："[疑惑的表情]/帮我看看这个/[文档]/算了不用了"——媒体位置决定语义（"帮我看看这个"指向文档，"算了不用了"可能放弃它）；此前防抖合并把全部文本拼一段+全部媒体殿后，**位置丢失**（示例插件 continuous_message 2.9.0 的 reconstruct_event 同样"文本一个 Plain+图片殿后"，未做保序——我们超越）。
- **三层实现**：
  1. **防抖收集**（`_extract_content`）：新增返回 `segments`（组件链原始顺序的文本/媒体交错片段：text/image/face/file/share/video/record）；items/session 保存；命令清理与撤回队列同步重建；
  2. **防抖重建**（`_reconstruct`）：有 segments 时按序重建组件链——连续文本用合并分隔符（\n）合成一个 Plain，媒体组件（Image 重建/保留组件原样）插在对应位置；无 segments/构建失败回退旧结构；纯文本消息=单 Plain（与现状等价，回归面小）；
  3. **接管注入**（`build_ordered_media_script`，接管/走主链共用）：从保序组件链渲染带序号脚本，媒体行内嵌会意（识图转述/文件摘要/链接标题，与 build_media_note 同成本），多条加 ①②③ 编号、纯文本多条同样编号；异常/无组件链退化聚合 note（措辞改"这一轮还发了"）。
- **冲突分析（已核查）**：接管改换/接管走主链=共用保序脚本（正收益）；放行/监视=事件组件链保序（主链所见即真实顺序）；防抖判定/润色读文本版不受影响；记忆插件从组件链记录媒体标记更准；纯文本场景与旧行为等价。
- **实测单测**："帮我看看这个/File(方案v2.pdf)/算了不用了" → `①帮我看看这个 ②[文档/文件：方案v2.pdf]：这份方案有 A/B 两个版本 ③算了不用了`。
