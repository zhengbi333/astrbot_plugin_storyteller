# alpha-0.234

## 「智能沉默」独立成模块（面板单开「沉默」选项卡，紧邻「拦＆改」）

### 为什么改
沉默闸门此前**没有自己的页面**：它的配置被塞在「关系」页右栏，而且界面上叫「**关系判断模型**」/「关系判断开关」；
更麻烦的是它和「关系判断」**共用同一个模型键** `pipeline.provider_id`，并且判定时**先借用「表情包判定模型」**
（`emoji.judge_provider_id`，那个名额另有表情包语境判定在用）。结果：
- 你看不出这个闸门在哪、用什么模型；
- 连续沉默上限 `silence_streak_limit` **面板上根本改不了**（前端零引用，只能手改配置文件）；
- 判定模型配在「表情包」页会盖掉「关系」页那个，配在「关系」页又会被误解成关系模块的东西。

### 改了什么
1. **新增配置模块 `silence`（标题「智能沉默」）**，模块顺序紧邻 `intercept`，面板单开「沉默」页（在「拦＆改」右边）。
   六项：`enabled`（总开关）/ `provider_id`（判定模型，独立名额）/ `silence_streak_limit`（连续沉默上限）/
   `brief_enabled`（允许草草回复）/ `context_enabled`（判定时附带时间与日程）/ `night_silence`（睡觉·深夜可沉默）。
2. **新增 Python 模块 `silence.py`**：集中配置读取、判定情境组装与规则文案；
   **旧键 `pipeline.judge_enabled` / `takeover_judge_enabled` / `silence_streak_limit` / `provider_id` 全部继续兼容**
   （新键优先、未显式配置才回退），升级不丢你已改过的值。
3. **模型名额各归其位**：沉默判定只用自己的 `silence.provider_id`，不再借用表情包名额；
   同时给「关系判断」（印象提炼 + 好感度微调）**独立出 `relationship.provider_id`**——
   它此前和沉默判定共用 `pipeline.provider_id`，两边都保留旧键兼容。
4. **判定器现在能看到「此刻时间 + 她此刻在做什么」**（此前提示词只有 671 字符，既无时间也无日程）：
   实测注入内容形如 `此刻时间：2026-10-04 01:35（周日，凌晨）/ 她此刻按日程正在：深睡 / 她现在是否在睡觉：是`。
   这是「凌晨一点该睡就不回」能真正判出来的前提。
5. **规则文案修正**：silence 规则明确写入「她正在睡觉或深夜困倦，而对方只是「在吗」这类无实质搭话，也应当判 silence」；
   brief 规则明确「**不要用它表达想回短一点**」——此前判定模型把 brief 当成「回短一点」，
   把你那次已经生成好的「嗯。 在。」**整段覆盖成「嗯。」**（内容丢失）。
6. **加保险**：`brief_enabled` 可整体关闭草草回复；brief 文本异常偏长（>20 字）时按正常回复处理；
   连续沉默上限仍在 main.py 计数并有上限保护（达上限强制回复一次）。
7. **面板新页**（样式与其它模块一致）：左栏＝判定状态（含「判定模型当前能看到」的情境预览）/ 最近沉默记录 /
   连续沉默计数（可单会话或全部清零）；右栏＝回复链路总开关 + 总开关 + 六项设置卡。
   同时：设置页不再重复展示、清障自检新增「智能沉默」与「沉默 · LLM」两项、模型页新增「沉默判定」行。
8. **顺手补回两个"无处可改"的隐藏开关**（都是自查时发现的）：
   - `pipeline.enabled`「回复链路总开关」原本只在「关系」页露出，判定归位后就会失去入口 →
     放到「沉默」页设置区最前（它关掉时判定根本不会执行）；
   - `pipeline.avoid_repeat_openers`「避免口头禅重复」与 `pipeline.opener_nudge_enabled`「口头禅点名提醒」
     此前**面板上没有任何入口**（回复链路模块被排除在设置页之外）→ 语义属于说话方式，收纳到「风格」页新增的
     「口头禅」设置区。

### 兼容性说明
- 所有旧配置键继续被读取（新键优先），**不需要手工迁移**；
- 新增的 `context_enabled` / `night_silence` / `brief_enabled` 默认开启；
- 若你此前只在「表情包」页配过判定模型：现在沉默判定不再借用它——
  请在「沉默」页的「判定模型」里选一次（留空则按「留空回退模型」策略走全局回退模型）。
