# alpha-0.152

## 衣柜第二轮反馈修复（性别贴合 + 逐件应用 + 取消📌可解除 + 生成去重）

### ① 生成贴合角色性别/身份（男生不再出裙子）

- 根因：生成衣柜只注入了说话语气（voice.tone），**没有注入人格注入体（身份/性别/性格）与身份锚**——模型不知道角色是男生。
- 修复：生成时注入 **persona 注入体（人格注入体，含身份性别世界观）+ identity.custom_text（身份锚）+ 语气 + 天气**；提示词明确要求"**必须贴合角色性别/身份/性格与生活场景**——角色是男生就给男士日常单品（T恤/衬衫/卫衣/牛仔裤/运动鞋），绝不出现裙装/连衣裙/丝袜等女性化单品，除非设定明确是女生"。

### ② 预览改为逐件「应用 / 删除」

- 移除「应用全部到左栏」；右栏预览每件独立两个按钮：**应用**（加入衣柜，满容量单独提示）/ **删除**（从预览移除）；每次生成仍重置预览。

### ③ 取消手动标记=真正解除

- 重要字段重构为 `important_auto`（自动：用户添加/对话添加/夸奖 → 蓝线）与 `manual`（手动📌 → 橙线）两维；
- **取消📌只清 manual**：若该衣物的重要只来自手动 → 完全变普通（不再"重要且无法取消"）；若它同时是自动重要 → 保留蓝线；
- 旧数据自动迁移（旧 important 视为 important_auto）；置换保留 = important_auto or manual。

### ④ 生成与现有衣柜明显不同款

- 提示词改："**与现有衣柜明显不同款**——不要重复/微调现有款式（有了白T恤就来黑卫衣而不是再来一件白T恤）"；现有衣柜仅作"避重参考"；
- 后端**相似度去重**（difflib，>0.82 剔除）：与现有衣柜同名/高度相似、生成内部互相重复的都过滤；去重后为空时明确报错提示重试。
