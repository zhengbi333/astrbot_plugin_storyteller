# alpha-0.69 —— 风格模块：三栏布局 + 风格生成模型 + 人格选择

> 实现风格模块改造需求：左/中/右三栏、新增「风格生成模型」直连配置、一键生成前的人格选择（自动填充）。

## 新增 / 变更

- **风格页三栏**：
  - 左＝说话风格档案（六维 + 口头禅，全部卡片化背景板）
  - 中＝一键生成（人格选择下拉 → 自动填充输入框）+ 示例
  - 右＝风格设置（总开关 + **风格生成模型**下拉 + 机理说明条）
- **风格生成模型**：新增 `voice.provider_id`（下拉、走「留空回退模型」策略）；「一键生成」改为直连该模型（原用主链默认模型），驳回时报错并输出报错日志；接入 Token 统计。
- **人格选择**：一键生成输入框上方新增「人格选择」下拉，枚举【为你篆刻的历史】已有人格（`list_personas`：name/description），选择后自动把人格描述填入输入框；无联动则提示手动填写。
