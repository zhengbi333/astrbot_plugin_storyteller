# alpha-0.48

- **拖拽改为指针事件实现，iframe 内置页面可用**：弃用 HTML5 拖放（其在 launcher 内置 iframe 页面中不可靠，表现为禁止符号/拖不动），改为 Pointer Events 自实现——`pointerdown` 拿起、`pointermove` 跟随、`pointerup` 落定，浏览器直接访问与 launcher 内置页面均正常；
- **滑动让位交互**：拿起选项卡后跟随鼠标，其周围选项卡平滑滑开（左右让位）露出插入位置；拖到最右空白处=移到末尾；松手落定后全部归位并自动保存（提示「已保存」）；
- **细节**：位移超过 5px 才视为拖拽（纯点击不误触）；拖拽中的被拖项抬升高亮（青绿光晕 + 阴影）；拖拽结束 60ms 内抑制误点击；触摸仍为点击切换；
- 模拟操作测试升级为指针事件序列（拿起/让位/落定/末尾/纯点击/抑制窗口），23 项全部通过。
