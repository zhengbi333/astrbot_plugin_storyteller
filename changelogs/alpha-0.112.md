# alpha-0.112（主动消息记录：真实失败原因 + 一次尝试一条）

## 修改

- **发送失败写明真实原因**：`_send` 返回 `(ok, reason)`——会话无法解析（目标 QQ 号/平台前缀）、
  平台未提供发送接口（适配器未接入）、发送接口返回失败（适配器未连接/目标不可达）、发送异常详情；
  `_maybe_send` 记录该原因到候选/报错台，不再泛泛"发送失败，稍后重试"。
- **一次"立即尝试"只留一条记录**：先生成的"生成中"在成功/失败时**原位更新**为"已发送/发送失败"（同一条），
  不再出现"生成中 + 发送失败"两条。
- **报错汇报台**同步带真实原因。
- 候选记录样式此前已改为消息记录式（结果标签 → 内容 → 时间素材）。

- compileall、inspiration 11、verify_057 88、chat_text 35 全绿。（注：主动发送失败原因需真实平台复现验证）
