# alpha-0.47

- **修复拖拽显示「禁止」符号**：Chrome 硬性要求 `dragstart` 里必须调用 `dataTransfer.setData()`，否则拖拽会话不成立、光标显示禁止符号——已补上；
- **放宽放置判定**：悬停在任意选项卡（包括被拖项自身）都执行 `preventDefault` 允许放置，不再出现禁止光标；
- **容器兜底**：拖到选项卡条空白处 = 移到末尾（同样允许放置、自动保存）；
- **防冒泡**：选项卡 drop 时 `stopPropagation`，避免与容器兜底重复移动。
- 模拟操作测试增至 18 项（新增 setData 调用、自身悬停 preventDefault、空白处释放移末尾等断言），全部通过。
