# alpha-0.13（2026-08-08）

## 变更

- **修复清除背景图报错**：
  - 根因：清除接口调用 `apiPost("appearance/background/clear")` 未传 body，诊断日志代码
    `JSON.stringify(body).slice(0, 100)` 对 undefined 调用 slice 抛错，导致请求从未发出；
  - 修复：`body || {}` 兜底。
- **背景图升级为壁纸库**（类似系统壁纸功能）：
  - 支持多张背景图：上传的图片进入壁纸库（文件按指纹 `bg-<hash>.<ext>` 存储，自动去重）；
  - **上限 5 张**：超出后按添加时间自动丢弃最早的一张（含文件清理）；
  - 缩略图小框排列展示（120px 缩略图，点击切换背景）；
  - 「删除当前壁纸」：删除选中项，图库仍有其他图时自动切到最近添加的一张；
  - 上传新壁纸自动选中并启用背景效果；
  - 旧版单图（`bg.png`）自动迁移进图库（含压缩处理）；
  - 新增接口 `POST /appearance/background/select`（切换壁纸）。
- 页面资源版本参数升至 `?v=0.13`。

## 说明

- 已有背景图（含 4.3MB 旧图）会在下次读取时自动迁移进壁纸库。
- 版本备份：工作区 backup 目录下的 `astrbot_plugin_storyteller_alpha-0.13`。
