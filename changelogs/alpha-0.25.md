# alpha-0.25（2026-08-08）

## 变更

- **修复切换动画消失**：
  - 根因：`.data-in`（异步数据淡入）类在 CSS 中定义于 `.view-anim` 之后，设置页数据填充时
    曾对视图容器添加 `data-in`，其 `animation` 属性覆盖了 `view-anim`，且该类残留——
    之后所有页面切换动画都被覆盖成极淡的淡入（视觉上「动画没了」）；
  - 修复：切换动画前移除视图容器上的 `view-anim` 与 `data-in` 残留；设置页不再对视图容器
    使用 `data-in`（异步填充的轻淡入仅用于子容器，不影响切换动画）。
- 页面资源版本参数升至 `?v=0.25`。

## 说明

- 版本备份：工作区 backup 目录下的 `astrbot_plugin_storyteller_alpha-0.25`。
