# alpha-0.28（2026-08-08）

## 变更

- **命令消息全面放行（不限 /reset，覆盖所有插件命令）**：
  - 命令识别增强：支持全角前缀（／！＃﹟）、剥离 @/引用/CQ 装饰后判断（如 `@bot /reset`、
    `[CQ:at,qq=…]/help`）、纯符号消息（如「……」）——这些此前会被误收集静默，导致命令失效；
  - 通用兜底：防抖入口检查事件是否已被其他处理器接管（`get_result()` 非空或 `is_stopped()`），
    是则一律放行——其他插件注册的命令/处理器（set_result 或 stop）天然不受防抖影响；
  - 命令消息到达时丢弃防抖缓冲（不合并发送），命令本身干净交回命令系统。
- 页面资源版本参数升至 `?v=0.28`。

## 说明

- 专项验证：完整命令识别（8 种形态）、既有防抖冒烟 6 项全过。
- 版本备份：工作区 backup 目录下的 `astrbot_plugin_storyteller_alpha-0.28`。
