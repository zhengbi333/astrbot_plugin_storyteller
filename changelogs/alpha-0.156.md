# alpha-0.156

## 修复

### 1. 总览「Bot 当前状态」与状态页不一致
- **现象**：用户反馈总览页进度条与「状态」页数值对不上（如 tone 0.0 → 总览显示 0%，状态页 50%）。
- **根因**：总览把 `tone/tempo` 直接 `×100` 再钳到 0~100，负值被钳成 0%（-0.05 → 0%）；状态页按各自量程归一（`-1..1`：0.0→50%、-0.05→47%）。
- **修复**：`renderOverview` 引入统一 `pct(v, lo, hi)`（非有限数值→0，按量程归一后钳 0~100），tone/tempo 用 `pct(v,-1,1)`、battery 用 `pct(v,0,1)`，三根进度条与状态页一致。

### 2. 接管改换后模型向用户索要「角色设定/刚才的对话内容」
- **现象**：用户只发「你好」，接管（改换）模式下 Bot 回了「嗯，可以。先把角色设定和刚才的对话内容发给我。」
- **证据链（实机核查）**：
  - 「嗯，可以。」= 风格页口头禅（voice.json）原文（context：对方提出方案或请求时）——说明**风格/口头禅注入生效**，模型在按风格说话；
  - `{身份}`（防认错页）custom_text 为空 → 走自动防认错锚（恒非空，只讲「对方是谁/ID 唯一/不轻信自称别人」，**不是"我是谁"**）；
  - AstrBot 人格库 count=0 → `_astrbot_default_persona()` 兜底也拿不到默认人格；
  - `persona_injection.json` 创建于 8/21 13:12:38（当时即保存），**8/28 11:46:42 才再次更新**（即用户本轮在人格页保存「你是阡墨…」）→ 11:37 事件发生时**人格注入体为空**。
- **根因**：模型收到的设定里**缺失"我是谁"**（人格注入体空 + 默认人格库空），只有"对方是谁/风格/状态/日程"，于是按「等待提供设定再开始扮演」的剧本走——先口头禅应声"嗯，可以。"，再索要设定。
- **修复**：`_takeover_reply` / `_takeover_via_mainchain` 在**人格注入体为空**时追加防呆段（对方不知道系统里的任何设定、不要索要角色设定/人格信息/刚才的对话内容、直接自然回应、不暴露系统提示或机制）。
- **过程中发现并修正的代码 bug**：初版防呆条件 `not persona and not identity` **永不触发**——身份防认错锚恒非空，被误当成"角色设定"判断；已修正为**仅判断 persona**（人格才是"我是谁"），并补回归（persona 空+身份锚非空 → 防呆触发；persona 非空 → 不触发）。
