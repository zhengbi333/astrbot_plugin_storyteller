# alpha-0.178

## ① 生图意图「上下文联动」：A 规则 → A1 上文 → B 智能判定（实验）

- **用户场景**：上一条「你那边的云怎么样」，下一条「给我看看？」——应当结合上文命中生图（画云），而不是当聊天放过。
- **实现（按用户定夺：A+B 都做，B 为橙色实验开关）**：
  - **A0 规则直判**（原有 `detect_image_intent`，支持「拍一张自拍/画只猫」等）；
  - **A1 索图式短问 + 会话上文**：当前消息为「给我看看/拍我看看/让我看看/看看呗…」等短句（≤20 字、不含日程/安排/资料等非画面任务词）时，取同会话 **10 分钟内**最近一条有效用户发言（记忆插件时间线，过滤系统/操作/命令）→ 以该发言为画面主题命中（via=context）；
  - **B 智能判定（实验，慎用）**：`image.judge_enabled`（默认关，生图页左栏**同防抖橙色 smart-zone**：橙色大开关 + 「实验，慎用」标签）——A 层未命中且当前消息含弱信号（看看/拍我/画/图/照片…）时，调**独立轻量模型** `image.judge_provider_id`（不占其它名额）、超时 `image.judge_timeout`（默认 8s）、上下文条数 `image.judge_context_count`（默认 3 条 1~8，**含机器人回复**，按用户确认"条数"口径）；输入=当前消息+最近对话（正序、每条 120 字）+判断规则提示+JSON 输出约束；**未配置/超时/异常=安全回退不拦截聊天**。
  - 页面验证：生图页左栏新增「智能判定」面板（开关/模型/超时/条数），提示原文置底。
- 验证：后端 `py_compile` 全通过；schema JSON 合法（image 新 4 键）。

## ② 占位符口径统一（前端硬编码 14 → 后端下发 16）

- 此前：后端模板引擎 16 个（含 `{穿搭}{回复}`），前端按钮 chips **硬编码 14 个**（缺 `{穿搭}{回复}`），且实际默认模板 15 个（缺润色专用 `{回复}`）——口径不一致。
- 修复：`intercept/status` 增加 `placeholders`（`intercept.placeholder_list()` 同源下发）；前端 chips 优先用后端清单（16 个），硬编码常量仅作旧版兜底；默认模板 `DEFAULT_TEMPLATE` 本就是完整 15 个（仅缺 `{回复}`，属润色专用，不改动）。
- 你的自定义模板（11 个占位符）不受影响；拦＆改页现在可一键插入 `{穿搭}` 等。

## ③ JSON 解析再增强：缺失引号修复（模型偶发畸形不再每次重试）

- 0.176 修复聚合后，仍观测到模型偶发输出**缺引号**畸形：`"end": "07:30, "activity"...`（值缺后引号，2026-09-06 15:37 实机日志）。0.173 的"失败重试一次"能兜底，但代价是多一次调用+6 秒。
- 修复：`json_util._fix_missing_quotes` 增加两类修复（①值缺后引号：`"07:30,`→`"07:30",`；②键缺前引号：`[start":`→`[{"start":`），在宽松解析的「修尾逗号→缺引号→尾截断」链中追加；合法 JSON 断言限定不受影响。

## ④ 见闻（搜索）空 API Key 显式提示

- 此前 Tavily 引擎 key 为空时自主浏览/手动搜索**静默失败**（用户无感知）。
- 修复：内心页搜索设置卡在「Tavily + 空 key」时显示橙色提示（提示填写 key 或改用 Bing）。
