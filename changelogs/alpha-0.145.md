# alpha-0.145

## 新增「模型」选项卡：全插件模型配置集中点（清障之后，三栏）

- **导航**：`模型` 插在「清障」之后（第 3 位），23 个选项卡；后端 `KNOWN_TABS` 同步（22 → 23）。
- **页面内容**：三栏 grid（窄屏折叠单栏）汇聚**本插件全部 17 个模型配置项 + 回退模型 2 项**：
  - 左栏「回复链路与生成」：接管改换（拦＆改）/ 润色 / 回复判定 / 抢话裁决 / 防抖智能判断 / 表情包判定；
  - 中栏「日常生成」：状态 / 日程 / 主动 / 搜索整理 / 风格生成 / 人格生成 / 穿搭生成；
  - 右栏「内心与记忆」：梦境 / 思考 / 日记（内心世界）、嵌入 / 画像 / 约定（记忆）、识图。
- **双位置同源**：本页每一项与各模块页渲染的是**同一个 `data-setting` 配置变量**（同一个 `saveConfigValue` → `config/module/update` → 后端同一键）。在模型页改、或去模块页改，保存到同一处；两个页面打开都显示当前值。交互模拟已验证「模型页改接管模型 → 拦改页下拉同步选中」。
- **回退模型重点卡**（左上第一块）：红色 2px 边线 + 橙色渐变背景板 + 红色阴影与标题染橙（`.models-fallback`）；内含「留空回退模型」开关（橙色样式保留）与「回退模型」下拉。
- 各模块分组用小标题（模块中文名 + 键名）；嵌入模型字段沿用「嵌入分类」列表（含列表来源标注）。
- 数据源全部走既有接口（`config/schema` + `models/providers`），后端零新增路由。
