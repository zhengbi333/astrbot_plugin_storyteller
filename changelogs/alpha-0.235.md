# alpha-0.235 · 2026-10-04

修复智能沉默在主链与接管之间的行为分叉，并让话量配置真正进入风格锚。

- 主链和接管共用连续沉默上限；上限为 0 时不主动沉默。关闭模块、判定失败或本轮已执行工具时恢复正常回复并重置计数。
- 主链判沉默时清除既有 `result_chain`，避免空文字却仍发出原消息链。
- 夜间规则保留为可选行为：从「应当沉默」改为「可以沉默」，明确不忽略实质问题、求助或未回应请求。brief 仍只作极短反应，异常空/长输出保留正常回复。
- 关闭日程不读取陈旧睡觉安排；「睡不着、起床」等否定/清醒活动不再因包含「睡」而被判为正在睡觉。
- `voice.verbosity` 非空时覆盖档案话量，留空沿用档案；补齐风格页配置入口，保留原字段自动保存机制。
- 预览壳从真实 metadata 读取版本，消除截图写死 alpha-0.202 的误导。

根因：计数闸门仅在接管路径执行，主链 LLMResponse 同时携带发送链，睡觉判断只是子串检测，话量配置未进入风格锚。

验证：既有 26 批本地回归 541 项，本轮第 52 批 40 项，原智能沉默验收 43 项；真实总结/工具/数据库快照与新端到端 27 项。前端截图和实际部署验收见工作区 `REVIEW_REPORT_2026-10-04.md`。
