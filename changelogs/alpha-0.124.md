# alpha-0.124

## 表情包独立判定名额（问题 1）

- 新增 `emoji.judge_provider_id`（`emoji_judge` 功能键）：表情包语境判定用**独立直连 LLM**，与「判定模型」（关系判断/沉默草草判定）互不排队；表情包页右栏新增下拉。
- 留空按「留空回退模型」策略解析（通常回退到判定模型渠道，可填不同模型提速）。
- 判定流程不变：回复 → 判定（emoji_judge）→ 概率闸 ×反馈权重 → 习惯组选图 → 发送。

## 「同图去重」→ 习惯组（问题 2，采纳你的纠正）

- **移除「不重复」语义**：人不会刻意避开同一张，而是有一套**惯用表情包组**——特定语境/情感发惯用的那一张或语义相近的不同张。
- `pick` 改为**按发送历史频率加权**：用得多的高频图权重更高（1 + 次数×1.2，封顶 6），同时保留随机轮换（换不同张）；无历史时均匀随机。
- `duplicate_days` 默认 3 → **0**（默认不去重；>0 时才启用「N 天同图不重复」，作为可选项保留）。

## 修复：接管改换的会话历史缺失（问题 3——你说的没错，之前确实没解决）

核对结论：
- **用户消息记录**：deepmemory 捕获在 on_message（事件层），接管不吞——已正常；
- **Bot 回复记忆回填**：`_note_bot_reply`（时间线 role=bot，0.116）+ 缓冲模式逐条 `_note_bot_reply_by_session`——已正常；
- **AstrBot 上下文缺失 ← 真缺口**：接管 stop 主链 → AstrBot 会话历史写入（agent 路径）不执行 → 下次主链对话上下文缺这轮；
- **修复**：接管发送成功后 `_archive_bot_reply_to_history`（官方 add_message_pair：user=用户消息、assistant=本轮回复，cid 取/建当前会话；缓冲模式写完历史后再分条发）。
- **其他注入插件**：接管时 stop 阻断主链 LLM——其它插件 on_llm_request 注入不生效属接管设计（记忆/人格/锚由我们自行注入，功能不缺失）。
