# alpha-0.157

## 修复：/reset 后首次对话仍「索要设定」——上下文/记忆为空时的假承诺与空白陷阱

- **现象**：任意一次 `/reset` 之后的第一句「你好/你好喔？」，接管模型回复"我这边没看到你说的设定和上下文……可能没贴上来？补一下就行"；12:13 非 reset 后的句子则正常（"嗯，你好。想说什么？"）。复现规律 100%：**每次 /reset 后必现**。
- **证据链（实机核查）**：
  - `/reset` 会清空 deepmemory 的 timeline（"已清空未总结缓存"）+ AstrBot 主链会话历史 → 插件「{上下文}」与「{记忆}」注入为空（12:13 快照 context=53 字，12:14 reset 后 timeline 只剩 3 条记录）；
  - **诱因一（假承诺）**：防认错锚原文"提示：发给你的提示词里已含当前对话、记忆与上下文，下面是区分人物的提醒……"——模型读到这句**承诺**，去核对「当前对话、记忆与上下文」，发现全是空白，于是认为"用户没把设定和上下文贴上来"，转而追要；
  - **诱因二（空白陷阱）**：模板里 {上下文}/{记忆} 为空时替换为**空白行**，模板内没有一处说明"空=没有更早记录"，模型无法区分"没贴"与"本来就没有"。
- **修复**：
  1. **防认错锚取消假承诺**（persona.py）：改为"提示：下面只讲「当前对话的这个人」怎么辨识……如果当前对话、记忆或上下文为空，那就是还没有更早的记录，直接按对方的这句话回应即可，不要追要所谓「设定」。"
  2. **空段注入明确占位**（main.py 接管两条路径）：`{上下文}` 空 →"（本次会话从这里开始，没有更早的对话记录。）"；`{记忆}` 空 →"（暂无与对方相关的记忆）"——模型明确知道"空是正常状态"，不再怀疑用户没贴。
  3. 0.156 的 persona 防呆段（人格注入体为空时）保留，与以上共同构成"无设定/无记录"三类空态的兜底。
