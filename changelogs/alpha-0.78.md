# alpha-0.78 —— 状态模块改造：轻量事件演化 + 演化只用「当下」+ 涟漪保留 + 可配置染色间隔

> 回应「状态怎么随对话/事件变」「要调记忆吗/调什么/走什么/需不需联动」的追问，
> 按定稿重新实现：长期记忆**不再是情绪驱动器**；实时情绪由状态内部「事件余波 + 时间底色」驱动；
> 记忆只在「心事素材」可选时按当前会话取最近约定 top1（标注联动、不走 embedding）。

## 变更

- **轻量事件演化（不调 LLM）**：对话中的情绪词/求助/道谢/争执 → 即时染色心绪 + 留下「互动涟漪」与「最近余波」；
  每次读取 {状态} 按时间底色揉动语气走廊。——这是常态的"随对话流动"路径。
- **演化输入只用「当下」**：时间 / 时间底色 / 日程 / 天气 / 最近余波 echoes / 最近对话 / 上次状态；
  不再读长期记忆作为情绪来源（避免"库存咖啡式"串味）。
- **心事素材（可选）**：新开关 `memory_drydock`（默认关）：开启且已联动【为你篆刻的历史】时，演化按当前会话取最近约定 top1 作「心里挂着」素材（**标注联动、不走 embedding、不驱动情绪**）；未装载跳过并提示。
- **涟漪/余波保留（修复）**：自动演化保存时不再清空事件涟漪与余波（LLM 输出不含时保留既有）。
- **染色间隔可配置**：`stain_interval`（分钟，默认 5）控制对话中情绪染色的最短间隔。
- 页面：状态页左栏新增「最近余波」展示；设置栏新增「心事素材」「染色间隔」；演化区说明更新（状态随对话怎么变的三段式）。
