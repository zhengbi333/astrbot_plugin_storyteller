# alpha-0.189

## 会话搜索意图：说「帮我搜一下 X」现在真的去搜，不再凭空编

- **背景（实机验证）**：用户给 Tavily 配好 API Key 后测试「帮我搜一下 5090 显卡价格」——之前对话模型只是顺着话编了一段，并没有真的搜索（Tavily 只被「主动对话/**自主浏览**」用）；本次把「对话里明确要我搜」这条链路接通。
- **触发**：`_SEARCH_INTENT_RE` 命中（帮我搜/帮我查/搜一下/搜下/搜搜/搜索/查一下/查查/查下/查询/查资料/查个/查点/上网查/百度一下/查查看/搜搜看 + 价格词：多少钱/价格/报价/行情/售价/价位）；排除词（日程/安排/计划/设置/配置/命令/消息/记录/文件/账单/数据/账）命中则不搜（查日程/查消息是本地信息）。
- **查询词提取**：`_extract_search_query` 取「搜索动词之后」到第一个句末标点（？。！；/换行）的片段，前缀清「的帮请个点嗯啊哦诶哎」、尾部清标点/语气助词；触发词先长后短（「帮我查一下」整体剔除，防「帮我查」截断残留「一下」）；「5090多少钱」这类价格词直接保留。
- **真实搜索链**：`on_llm_request` 接管模板组装前调用 `mind.search_and_think(self, query, count=5)`（Tavily 真实请求 5 条结果 + LLM 归纳见闻）；结果（含归纳 + 前 3 条带 [1][2] 来源编号）存入 `_search_result_cache`（会话粒度，10 分钟过期），`{搜索结果}` 占位符在 `_anchor_values` 中替换进模板——对话 LLM 基于真实网页内容作答，并被告知「没把握就说不确定，别编造」。
- **借鉴 AstrBot 主程序搜索工具的三个做法（独立实现）**：
  1. **失败可见**：`_http_post_json` 非 200 不再吞成 None，抛带状态码异常；会话搜索失败也缓存「如实告诉对方没查到」备注，让搭载 LLM 如实转述，而不是查无结果时硬编。
  2. **官方答案兜底**：Tavily payload 增加 `include_answer: True`，引擎直接答案（answer 字段）在归纳模型没吐出内容时兜底（实测返回 171 字英文答案）。
  3. **结果编号引用**：备注条目带 `[1]` `[2]` 来源编号，模板提示「涉及数据可点出来源编号」。
- **新配置**：`search.conversation_enabled`（默认开；关闭则这类话只当普通聊天）。
- **验证**：意图正则/查询提取 10 组样本 ✓；Tavily 真实调用 5 结果 + answer 171 字 ✓；AstrBot 环境全模块导入 + 占位符 18 个（PLACEHOLDERS/ORDER/DEFAULT_TEMPLATE 均含 {搜索结果}）✓；py_compile ✓。
- **未覆盖**：非接管模式（监视/放行）不注入搜索结果；「今天有什么新闻」这类无触发词的查询不触发（可按需扩展触发词）。
