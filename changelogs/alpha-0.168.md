# alpha-0.168

## 修复：多句合并时"接住每一句"——对方连发多条最后的问句没被回答

- **现象**：用户实测三连发"hmmm / 这么冷淡 / 你在干嘛"（防抖合并为一条 14 字发给模型）→ 接管回复"在的。只是今天话少，没冷着你。"——**只接了"冷淡"的情绪，用户问的"你在干嘛"被漏掉**，直到用户又问了一次才回答（"准备休息。今天事情有点多，这会儿刚好充会儿电。你呢？"——那条本身非常自然）。
- **根因**：{当前说话} 合并多条后是一整段多行文本，模型"挑情绪最重的一句"回，没有"对方连发了多条、最后是问句应先回"的意识。
- **修复**：注入侧检测 {当前说话} 非标题行 ≥2 行（连发）时，追加一句温和说明：
  `【连发的习惯】对方这一条里连着说了上面几句——都接住；如果最后一句是问句，先回答它。`
  单条消息不追加（不打扰正常对话）。
- **顺带**：本轮实测同时确认 0.167 修复有效——"在。"（21:06:50）、"在的。只是今天话少，没冷着你。"（21:07:59）、"准备休息。今天事情有点多……你呢？"（21:08:34）全部正常、无索要痕迹、无检测兜底触发（日志无 WARN）。
