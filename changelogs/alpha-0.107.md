# alpha-0.107（日记拟人化收尾 + 思考间隔可配）

按用户四点拍板实现：

## 1. 日记依据明确（非乱生成）

- 日记素材（`_diary_material`，与日程/预览共用）：人格注入体 + 性格 + **记忆（约定/愿望/重要事 8 条）** + 亲近的人 + 当天状态史 + 梦/思/见闻 + 对方情绪——**记忆与人格都在**，写的是"她的人生的一天"。
- 新增「发给日记 LLM 的内容」展示板，素材与提示词原文全透明。

## 2. 日记本展示改「一篇 + 分页」

- 默认只展示**最新一篇**大卡；「上一篇/下一篇」逐篇翻（不刷屏）；「展开全部」保留历史查看；标题显示「已存 N 篇」。

## 3. 日记 LLM 配置独立 + 横向展示板

- **独立「日记模型」**（`mind.diary_provider_id`，留空随梦境模型 / 回退策略）——此前日记复用梦境模型，故看不到专属配置；
- **横向展示板**（日记本下方全宽）：`GET diary/prompt_preview` 只读拼装（复用 `_diary_material`），展示完整提示词 + 素材 + 生效模型，零 Token。

## 4. 思考最小间隔可配

- 新增「**思考最小间隔(分钟)**」（`mind.think_interval_minutes` 默认 60）；
- `_mind_loop` 触发条件改为：距上次思考 ≥ max(最小间隔, 30~90 分钟随机窗口) 且近期有事件——**间隔是硬下限**，越调小越"爱想"、越调大越"少发呆"。
