# alpha-0.144

## 布局修正 + 设置自动保存全面修复（用户三项反馈）

### 1. 「拦和改」页的「记忆联动」块：确认是错误归置 + 不能保存的坏块，已移除

- **排查结论**：该块是早期「设置 → 记忆联动」迁入的残留；「记忆」页早已有同 6 字段的完整「记忆联动设置」面板（且绑定保存正常）——同一组设置两处重复，其中拦和改这份**从未绑定保存事件**（`bindInterceptSettings` 只绑定 `#itc-settings`，记忆联动块在另一个无 id 的 grid 里 → change 无监听 → 永不落盘）。
- **修复**：从「拦和改」移除整个记忆联动 section（记忆页为唯一归宿）；记忆页面板不受影响。

### 2. 同类「渲染了但不保存」全面排查 → 又发现两处并修复

- **发送页**：4 个设置（短句间隔/长句间隔/抢话裁决/裁决模型）渲染了 `data-setting` 但从未调用 `bindSettingsIn` → 全部不保存。补绑定。
- **表情包页**：3 个设置（发送概率/同图去重/判定模型）同样未绑定 → 全部不保存。补绑定。
- **设置页**：`EXCLUDED_MODULES` 缺 `"send"` → 「发送缓冲」模块在设置页重复出现一个子选项卡（与发送页专属页面重复）。补排除。
- 全站 22 个渲染函数逐一核对过：其余页面均有 `bindSettingsIn`/对等绑定。

### 3. 防抖页：图片识图移入左栏

- 图片识图卡（7 个字段）原来挤在右栏设置列里把页面拉得很长；现移到**左栏**「防抖 LLM 请求与判定结果」面板之下，做成独立面板（双列 grid），右栏只留防抖自身设置。保存绑定随 `bindSettingsIn(view)` 自动生效。

### 4. 日程页：提示词预览移入中栏

- 「生成提示词（prompt preview）」卡原来横跨全宽悬在页面最底部；现移入**中栏「当天日程」面板下方**（不占窄栏、不再悬底）。
