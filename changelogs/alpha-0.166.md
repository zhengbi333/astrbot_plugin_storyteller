# alpha-0.166

## 注入标签升级为段落式【标题】+内容（用户建议：信息分明）

- **用户洞察**：注入标签用"对方刚刚说：xxx"冒号式不够分明；建议段落式——
  ```
  【对方刚刚说的话】
  xxxx
  【当前和你对话的人】
  xxxx
  【发送场合】
  xxxx
  【当前时间】
  xxx
  【在此之前的部分上下文】
  xxx
  【你的部分记忆】
  xxx
  ```
  （与内置默认模板的段落式风格一致）
- **修复**：`_labelize_anchors` 所有标签升级为段落式标题：
  {当前说话}→`【对方刚刚说的话】\n…`、{当前用户}→`【当前和你对话的人】\n…`、{场合}→`【发送场合】\n…`、
  {上下文}→`【在此之前的部分上下文】\n…`、{记忆}→`【你的部分记忆】\n…`、{天气}→`【今天天气】\n…`、{见闻}→`【你刚看到的见闻】\n…`；
  仍遵循"模板相邻 14 字内无标签词才加"（模板已自带【对方说】等标题则不改）。
- **说明**：上一版审计输出里"你记得对方上次提到喜欢喝咖啡。/证毕上次说他想养一只猫。"是 `dev/inject_audit.py` 的**演示样例**（真实 compose_injection 需调 LLM 合成）；实机 /reset 后记忆库为空→{记忆}为空（连标题都不加）。
