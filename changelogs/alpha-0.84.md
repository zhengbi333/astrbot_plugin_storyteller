# alpha-0.84 —— 消除状态页卡片间大块空白：固定列数网格 + 说明卡独立全宽

> 回应「中间的空白是怎么回事？」：原 `auto-fit` 网格在宽视口下卡片被拉成长条、
> 行内等高造成短卡（演化节拍记录）内部大空白；跨全宽说明卡还留下一行空列。

## 变更

- **`dash-grid` 改为固定列数**：宽屏 4 列 / ≤1180px 2 列 / ≤620px 1 列；
  7 张内容卡在 4 列下恰好 4+3 排满，**不再出现空列**。
- **卡片不强制等高**（`align-items: stretch` → `start`）：每张卡只占自身内容高度，
  「演化节拍记录」等短卡不再被行内高卡拉出大片空白。
- **说明卡移出网格**：「状态怎么随对话/事件变」改为网格外独立全宽卡
  （`presence-explain`，margin-top 14px），不再占网格列、不产生空列。
- 删除废弃样式 `.dash-grid .panel.dash-wide`、`.presence-dash > .rel-setting-note`。

- `verify_046_nav.js` 31 项 / 语法全绿
- 视觉自检：2048 / 1280 / 900 三档截图核对——无空列、无拉伸空白、无溢出
