# alpha-0.120

## 组合消息「像人」媒体感知（你定夺：全量做 + 链接读到要点）

用户一次发「表情包 + 文本 + 文件 + 链接」时，陪伴插件现在像人一样接得住：

### 回复侧（接管 / 放行统一会意）
- `vision.py` 重构为媒体感知模块：
  - `extract_media_parts`：图片（url/file）、QQ 表情（face 计数）、文件、视频、语音、链接（Share 组件 + 文本内正则，组合消息也提取）；
  - `build_media_note`：统一把整条消息组织成「（对方本条消息还附带发了：[图片] …；[文件] 名：摘要；[链接] 要点）」；
  - `summarize_file`：文本类白名单（txt/md/json/代码等）读前 2 万字符、LLM 概括 2-3 句（预算 _max_tokens=220、18s 超时）；
  - `fetch_link_context` + `summarize_link`：抓网页标题/meta 描述/开头 600 字 → LLM 一句话要点（预算 150 token、15s），抓取失败降级域名；不编造；
  - `with_llm=False`：关闭模型理解也只出基础标记（[图片×N]/[文件] 名/[链接] url），媒体消息永不静默丢失。
- 接入：
  - 接管改换（直连）：完整会意（含识图）注入 `{当前说话}` 之后；
  - 接管走主链：只补文件/链接（图片主链自己转附件，不重复烧钱）；
  - 放行模式：保留原识图注入 + 新增文件/链接会意注入。
- 新开关：`vision.file_summary`、`vision.link_summary`（默认开，同受 `vision.enabled` 总开关约束，防抖页识图卡）。

### 观察侧（轻量规则，不调 LLM）
- 纯表情包/图片/文件消息也算互动：关系好感微增（delta 0.012）、画像素材「对方发来图片×N」（供提炼交流方式）、互动缓冲附注（LLM 关系判断能感知对方常发图）；
- 组合消息：媒体附注进互动缓冲，不重复进画像。
