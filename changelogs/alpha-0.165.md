# alpha-0.165

## 注入体格式全面审计（用户要求：跑一次模拟注入，排查所有信息格式是否工整/严谨/规范）

- **新增审计工具 `dev/inject_audit.py`**：真实模板 + 真实数据（persona/voice/presence/schedule/wardrobe/relationships/mind 全部读实机文件 + 代表性记忆注入包）→ 走完整注入链（labelize → replace_template → 去框架注 → 空行压缩）→ 全文行号输出 + 问题扫描（残留占位符/连续空行/重复文本/敏感词）。以后每次实机异常可先用它跑一遍看实际内容。
- **审计发现并修复（0.165）**：
  1. **风格锚重复句**：`回复节奏：跟随对方节奏……（跟随对方节奏，别人简短我也简短……）`——build_voice_anchor 的补充说明与 voice.json 原文重复；改为只输出原文（`回复节奏：{rhythm}`）。
  2. **连续空行**：`{记忆}/{天气}/{见闻}` 为空时模板留白连排（3+ 空行）；注入后统一压缩 `\n{3,}` → `\n\n`。
  3. **标签不全**：0.164 只给 `{当前说话}/{当前用户}/{场合}` 加标签；本轮扩展到 `{上下文}`（"更早的对话："）、`{记忆}`（"你记得的："）、`{天气}`（"今天天气："）、`{见闻}`（"你刚看到的见闻："）——同样"模板相邻无标签词才加"。
- **审计确认无问题**：无残留占位符；无敏感词（以上设定/旨在说明/再造话术）；防认错/关系/风格/状态/日程各段标题齐全；段落说明句有段落标题归属（非裸行）。
- **遗留建议（未擅改模板，需用户定夺）**：用户模板中 `{人格}` 排在 `{记忆}` 之后（第 9 位）——模型读完 900 字系统信息才看到"我是谁"。建议把 `{人格}` 行移到 `{身份}` 之后（模板编辑器剪切即可；插件侧已对任意顺序正确注入标签）。
