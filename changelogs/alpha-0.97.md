## Key 排查结论（备忘）

- 插件直连使用的是 **AstrBot 运行时（内存）的 Key**——实机日志铁证：直连生成成功
  （说明运行时 Key 有效，与用户面板连通性测试一致）。
- `cmd_config.json` 文件里的 Key 是更早的旧 Key（SDK 实测 401：生成与列模型均失败）——
  **文件与内存不同步**（面板保存生效在内存、未落盘）。隐患：AstrBot 重启后按文件加载，
  旧 Key 复活会再次失败；需在面板把 Key 重新保存一次触发落盘。
