# alpha-0.104（日记日程化：到点自动写）

按用户拍板：日程嵌入 + 到点自动写。

## 改动

- **生成日程时固定排「写日记」段**：`build_schedule_generate_prompt` 新增要求 6——
  每天必须有一段『写日记』（默认 **23:30 前后、20 分钟**，可配），activity 写「写日记」，note 说一句（一天收尾）；
- **到点自动写**：`_mind_loop` 里新增 `_diary_due_now()`——按「写日记时间 ±30 分钟窗口」判定，
  到点且当天没写 → 自动 `_write_diary()`；0~1 点还没写（半夜）也补写；不再依赖"23 点硬写"。
- **新设置项**（日程页右栏展示板卡片，自动保存）：
  - `schedule.diary_time`（"写日记时间(HH:MM)"，默认 **23:30**）
  - `schedule.diary_minutes`（"写日记时长(分钟)"，默认 **20**，5~60）
- 日程预览面板同步提示要求 6；日记本标题显示「已存 N 篇」（1~3 篇也可见，让用户放心历史保留）。
- 日记生成保持 0.103 的"关闭思考 + max_tokens=1600"快速策略。
