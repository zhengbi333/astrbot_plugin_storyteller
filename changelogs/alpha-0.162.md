# alpha-0.162

## 修复：对话语义标签兜底——用户模板里 {当前说话}/{当前用户}/{场合} 替换后是裸文本

- **用户洞察（完全正确）**：看了实际发送内容后指出"我可没看到任何'以下是用户发送的消息'或'以下是部分历史对话'之类的提示出现"——替换后的文本是：
  ```
  （空两行）
  你是阡墨，一个18岁的男生…（322字人设）
  你好
  （空）
  证毕（<用户ID>）
  私聊
  当前时间：2026-08-28 17:00
  请以这个角色的身份自然回应对方刚刚说的话，不要提任何系统机制。
  ```
  **"你好"没有标签说明是"对方说的"；"证毕（<用户ID>）"没有标签说明是"当前和你对话的人"**——模型面对一坨无语义结构的文本，分不清谁说了什么，"没看到具体的对话内容/对方说了什么"由此而来（12:08"告诉我对方刚刚说了什么"完全吻合）。
- **为什么漏了**：内置默认模板每段都有标签（【对方刚刚说的话】等），但**用户自定义模板里的裸占位符，插件侧从未做标签兜底**；而调试时一直盯着"占位符有没有替换成内容"，忽略了"替换后有没有语义标签"。
- **修复**：接管两路径在替换后**强制追加结构化【本次对话】段**（与模板并存、重复无冲突）：
  ```
  【本次对话】
  对方刚刚说：你好
  当前和你对话的人：证毕（<用户ID>）
  发送场合：私聊
  更早的对话：…
  ```
  模型明确知道每行是谁说的。空态时该段只含现有字段（如无更早对话则不写"更早的对话"行）。
- 属于 0.159~0.161 系列修复的最后一环：user prompt 去敏感词（0.161）、去框架注（0.161）、索要检测+去框架重生成兜底（0.159~0.161）、本版标签兜底（0.162）。
