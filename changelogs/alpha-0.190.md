# alpha-0.190

## 会话搜索实机修复（0.189 首版部署后用户实测暴露）+ 上下文条数配置化

### bug①：查询词提取成「嗯...吧」（Tavily 搜了垃圾词）

- **现象**：用户发「嗯...帮我搜一下吧」→ 日志 `会话搜索已缓存 query=嗯...吧 note=580字`——搜索链路触发了，但查询词是垃圾（先全文剔除搜索动词的旧实现把句首语气词「嗯...」与句尾助词「吧」拼在一起）。
- **修复**：`_extract_search_query` 重写为**取「搜索动词之后」**到第一个句末标点（？。！；/换行）的片段，再清前缀语气词/尾助词：
  - 「帮我搜一下现在5090显卡的价格呗？咱的实验室也要购进一批设备了」→ `现在5090显卡的价格`（旧实现会连后半句一起搜进去）
  - 「帮我查一下苹果手机价格。另外帮我看看天气」→ `苹果手机价格`
  - 「5090多少钱」（无搜索动词、价格词命中）→ 原样保留
- **验证**：9 组提取样本全部符合预期（含弱查询判定「嗯...帮我搜一下吧」→ 空 → 走补主题）；py_compile ✓。

### bug②：只说「帮我搜一下吧」没带主题词 → 上文 24 小时补主题

- **现象**：用户隔夜回「嗯...帮我搜一下吧」（回应昨晚「帮我搜一下现在5090显卡的价格呗？」），旧实现搜索词为空直接放弃。
- **修复**：触发后查询词为空（弱）时，**从上文最近 24 小时找带搜索意图的消息补主题**，补到昨夜 `现在5090显卡的价格`；补不到才放弃（此时模板 {搜索结果} 不注入，对话模型自然回应）。
- **诊断结论（为何回复「晚点发你」）**：`{上下文}` 默认 limit=4，当前消息被去重后只剩机器人自己的回复（「我：一万六到两万五…」），用户「问过价格」的原话在窗口外——模型从自身回复猜到价格话题，但不知道上一轮搜索主题，故说「晚点发你」。

### 新增配置：`intercept.context_count`（上下文携带条数）

- **背景**：`{上下文}` 条数原为硬编码 `_recent_timeline_text(session_id, limit=4)`（接管改换 / 接管走主链两处），无配置项；条数太少时「问过价格的原话」落在窗口外，模型只能猜话题。
- **配置**：`intercept.context_count`，int，默认 4，范围 2–12（hint 已写清权衡）。两处硬编码改为读取（clamp 2–12）；会话搜索「补主题」回看条数同步跟随。
- **验证**：schema JSON 解析 + 键存在 ✓；py_compile ✓；AstrBot 环境导入 ✓。
