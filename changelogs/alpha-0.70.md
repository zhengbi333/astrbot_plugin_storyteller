# alpha-0.70 —— 风格模块补充：话量维度 + 节奏跟随 + 群聊降噪

## 新增 / 变更

- **话量倾向（新第七维 `verbosity`）**：惜字如金 / 适中 / 话痨偏长爱铺陈（可附单次句数偏好）；档案区新增字段，「一键生成」prompt 同步要求输出；内置示例补充该维度。
- **回复节奏跟随对方**：`{风格}` 锚里节奏文案固定附「跟随对方节奏：别人简短我也简短，别人细腻我也跟着铺陈」；一键生成 prompt 要求 rhythm 体现跟随。
- **群聊降噪（`group_quiet` 开关，默认开）**：`{风格}` 锚在群聊场合追加「收敛亲昵与私聊腔、不刻意外露状态、保持简短自然、别抢话」；在风格页右栏「风格设置」可开关。
