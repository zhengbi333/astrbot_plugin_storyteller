# alpha-0.36（2026-08-16）

## 变更

- **状态锚（状态/情绪模拟）**：`presence.py` —— Bot 的「此刻状态」（心情/精力/正在想的事），
  自然语言描述、非数值；支持手动编辑 + 按当前时间/日程一键生成；注入后只影响语气节奏，不降理解质量。
- **日程锚**：`schedule.py` —— 每日日程（时间→活动），按当前时间判断此刻在做什么，影响状态与主动对话；
  支持手动编辑 + 按人格一键生成；注入时只是素材，不照搬、不写成事实。
- **拟人化重写**：`rewrite.py` —— 统一把身份/风格/状态/日程四锚前置组装进请求；可选把用户消息
  轻量润色成更自然的表述（默认关）。
- **智能主动对话**：`proactive.py` —— 主动消息「有由头」而非随机定时：从状态/日程/记忆里的约定愿望
  取材；时间窗 + 随机间隔 + 每日上限 + 刚聊完顺延 + 未回应降速；LLM 生成、发送前校验。
- **记忆写入 + 用户画像**：`memory.py` —— 检测「约定/答应/以后要」写入承诺记忆；从最近对话提炼
  稳定偏好/习惯/身份，定期写入记忆插件（源插件标记为本插件）。
- **前端**：新增「状态」「日程」「主动」三个主选项卡；状态/日程支持编辑 + 一键生成；主动页展示状态
  与手动触发；全部修改即自动保存。
- **配置**：新增 `presence`、`schedule`、`rewrite`、`proactive` 大类；`memory` 扩展写入约定/画像开关。
- 页面资源版本参数升至 `?v=0.36`。

## 说明

- 全部模块独立实现，仅借鉴「状态影响语气 / 称呼锚点 / 候选有由头 / 双轴关系」等通用思路，
  未复刻示例插件代码（雷同扫描 0 处）。
- 状态/日程/主动/记忆写入均为可选，各自有独立主开关；未配置时不影响普通对话。
- 版本备份：工作区 backup 目录下的 `astrbot_plugin_storyteller_alpha-0.36`。
