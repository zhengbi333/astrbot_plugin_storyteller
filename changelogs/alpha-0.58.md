# alpha-0.58 —— 拦＆改

> 在「防抖」之前新增「拦＆改」选项卡，整合主链 LLM 请求的介入方式（监视/放行/阻断/接管改换）、
> 可编辑的「最终发送给对话 LLM 的信息格式」模板（模块占位符）与「最近发送给对话 LLM 的内容」实时面板。

## 新增

- **「拦＆改」选项卡（防抖之前，选项卡 15 → 16）**
  - 左侧：拦截设置（参与总开关 + 介入方式 + 记录条数 + 接管改换模型）+ LLM 请求拦截记录 + 用户当前请求（从调试页迁入，实时刷新）
  - 右侧上：「最终发送给对话 LLM 的信息格式」模板编辑区，占位符 {身份} {关系} {风格} {状态} {日程} {记忆} {天气} {见闻} {时间} 点击即插入
  - 右侧下：「最近发送给对话 LLM 的内容」实时面板（不区分模式，展示最近实际发给回复 LLM 的完整请求）
- **拦截介入方式（intercept.mode）**：监视（记录不介入）/ 放行（注入五锚+记忆后交主链）/ 阻断（静默）/ 接管改换（按模板组装提示词 → 直连接管模型生成 → 发送 → 阻断主链防双重回复）
- **接管改换模型**：intercept.provider_id（下拉，走「留空回退模型」策略；被驳回/生成失败 → 报错并静默阻断，不卡消息）
- 最近发送快照缓冲 SentRequestBuffer（环形 30）+ API `GET /intercept/sent`

## 变更

- 原「设置 → 拦截」子选项卡整体迁入「拦＆改」页左侧（设置页不再出现拦截）；调试页仅保留「诊断」
- 旧 `intercept.block_llm` 并入 mode；默认介入方式 = 放行（注入后交主链回复，升级后行为与拟人主链路一致）
- 每个功能模块可注入的消息由模板占位符统一控制，未来模块在此增加专属占位符
