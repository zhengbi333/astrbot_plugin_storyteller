# alpha-0.203 · 2026-10-02

修复工具循环和记忆联动的执行边界。

- 修复 `_image_wish_hint` 未等待协程导致后续生图判定被跳过。
- 能力总开关在声明和执行入口共同生效；同参数成功动作在同一事件内复用，避免重启/重试重复写入或投递；同类执行串行检查每日限额，防并发越界。
- 原生工具循环为所有调用回填结果，超额调用返回明确拒绝；最后一轮禁用继续调用，零轮预算不执行；校验本轮提供的工具和 JSON 参数。
- 用户补充消息后停止旧请求的后续动作；已执行动作遇到后续生成失败时，携带真实结果降级生成。
- 原生表情包工具的标记保留至发送阶段；图片无发送接口/目标或接口明确返回失败时，不能报告已发送。普通回复发送同样识别显式失败。
- `[DO:...]` 改为按括号及字符串边界扫描，支持嵌套 JSON，剔除截断参数；纯协议回复不再因空字符串回退而泄漏原标记。
- 工具每次模型往返的 token 全部累计，读取流式 usage 尾帧，区分缓存与普通输入；仅拒绝 thinking 参数时先移除 thinking 重试，不把 tools 一并永久关闭。
- 统一群归属、会话、人格上下文；主动由头和历史取当前目标的记录，减少跨会话内容混入。拆开重复定义的承诺素材助手；`context_count=0` 真正关闭上下文。

根因：异步真假判断、以字符串正则匹配 JSON、工具调用数与回填数不一致、缺少执行入口开关和并发闸门、桥接上下文字段不全、同名方法覆盖。

验证：原有 260 项本地回归 + 第十六批 34 项边界测试；真实 DeepSeek/Tavily 11 项、原生工具 5 项、运行数据库独立快照 11 项。最终结果见工作区 `AUDIT_REPORT.md`。

边界：承诺回访仍走既有由头与节制规则，并非精确定时提醒；无法撤销用户插话前已完成的工具副作用；放行/监视主链生成仍不可被插件中断。
