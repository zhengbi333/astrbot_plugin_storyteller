# alpha-0.40（2026-08-16）

## 变更（UI 整合打磨）

- **设置页模块化**：把有专属选项卡的功能（身份/关系/风格/状态/日程/主动/模型/表情包/穿搭）
  从设置页移除，各自在功能页管理；设置页只保留通用模块（基础/拦截/防抖/记忆联动/回复链路/
  识图/搜索/重写）。
- **功能区总开关**：每个功能区页顶部新增「总开关」——大尺寸、橙色（关系/身份/风格/状态/日程/
  主动/表情包/穿搭 8 处），开关状态即改即存。
- **字体可读性**：全局字体加大加粗（正文 14px、注释 13.5px、标题 16~22px），小字颜色加深，
  不再细得看不清。
- **顶部标签条加大**：标签条 padding/字号/间距整体放大，更醒目。
- **圆角变尖**：按钮/输入框/选项卡/弹窗圆角由 10px 收紧到 6px，整体更利落（贴合方角风格）。
- 页面资源版本参数升至 `?v=0.40`。

## 说明

- 新增 `wardrobe` 配置大类（穿搭与衣柜总开关）。
- 独立实现，未复刻示例插件代码（雷同扫描 0 处）。
- 版本备份：工作区 backup 目录下的 `astrbot_plugin_storyteller_alpha-0.40`。
