# alpha-0.3（2026-08-08）

## 变更

- **WebUI 全面换肤（空灵科技风 v2）**：
  - 布局重构：去掉左侧导航栏，改为顶部悬浮胶囊导航（品牌 + 居中导航 + 版本号），主体为居中窄栏 + 章节式排版（超大留白、无卡片盒、细分割线）；
  - 配色基调由蓝紫改为**青绿冷光**（teal → cyan 渐变），氛围光斑 + 细网格纹理，暗色模式同步；
  - 主题选择改为圆形渐变「色票」排布；明暗/背景板开关改为胶囊按钮；颜色选择为圆形色块 + 十六进制输入；滑块细线化。
- **修复交互 Bug：点击选项后界面不更新，需第二次点击才生效**：
  - 根因：`saveAppearance()` 为异步调用但未 `await`，界面在状态更新前即重渲染，渲染结果仍是旧状态；
  - 修复：所有外观变更改为「乐观更新」——本地状态与界面立即生效，再异步持久化，失败自动回滚并提示；
  - 顺带修复背景板开关连点时读取旧状态取反的问题（改为读取实时状态）。

## 说明

- 外观存储与后端 API 不变（`/appearance/*`），已有外观配置兼容。
- 版本备份：工作区 backup 目录下的 `astrbot_plugin_storyteller_alpha-0.3`。
