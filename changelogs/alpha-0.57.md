# alpha-0.57

- **开关配色调整（需求）**：所有功能总开关由橙色改为**纯红**（#ef4444，非渐变）；唯一例外是防抖「智能判断」实验开关（保留橙色 + 橙底「实验，慎用」标签）。
- **设置布局规则落地**：所有标签页内设置遵循「开关类聚前（总开关最前）→ 模型下拉/选项居中 → 数值与文本手动编辑在后」；防抖页「撤回过滤」开关移入「防抖总开关」正下方。
- **删除「模型」选项卡（16→15）**：12 个功能模型全部迁入所属模块页——
  - 状态/日程/主动 → 各自页内「模型设置」小节（下拉菜单）；
  - 做梦/思考 → 内心页「模型设置」小节（新建 mind 配置大类）；
  - 判定 → 设置页「链路」；润色 → 设置页「重写」；识图 → 设置页「识图」；嵌入/画像/约定 → 设置页「记忆」；搜索 → 设置页「搜索」；
  - 所有模型设置统一为**下拉菜单**形式（旧键 `models.xxx_provider_id` 自动迁移读取，已有配置不丢）。
- **「留空回退模型」策略（新）**：设置页「模型」子选项卡新增红色总开关无关的**橙色**开关「留空回退模型」（默认开）+ 「回退模型」下拉。开启：模块模型留空回退到回退模型；回退也空 → 报错并**驳回**该请求；关闭：模块模型留空直接驳回报错；模块内模型无效同样驳回（跳过该次 LLM 调用，不崩溃）。
- **防抖「智能判断」（实验，需求）**：开关 + 直连判定模型下拉 + 「判继续后无更新的最终等待时长」；开启后取代固定窗口与自适应计时。缓冲每次更新即直连判定「放行/继续」：放行立即合并发送给主 LLM；继续则重新计时完整最终时长；期间新消息再触发判定；无更新到点强制结算。判定模型不可用/超时/失败 → 回退固定窗口后结算（不卡消息）。
- **防抖页四个实时面板**：正在收集的内容、结算历史（原有）+ **防抖插件日志**、**防抖 LLM 请求与判定结果**（新，含发送给判定模型的内容/判定状态/剩余秒数）；按「设置 → 日志面板刷新间隔」轮询（默认 1 秒），离开页面自动停止。
- **模块化日志体系（骨架）**：log.py 重构——消息统一带「【为你续写的故事】【模块名】」前缀进 AstrBot 日志面板；内存环形日志按模块归类；新增 `GET /debounce/logs`（防抖模块日志）与 `GET /debounce/smart_log`（判定面板数据）；`GET /logs?module=xx` 可读取任意模块内存日志。
- **其他**：主链润色用户消息、约定/愿望提炼改用对应功能模型配置（不再硬编码默认对话模型）；所有模型功能调用点在驳回时安全跳过；模拟操作测试更新为 15 选项卡基线；新增防抖智能判断后端 smoke 测试。
