# alpha-0.158

## 修复：润色链路的「索要设定/要润色哪句」+ 提示词空态全面防御（系统排查）

- **现象演进**：0.157 修复接管模板空态后，实机 /reset 后仍出现更奇怪的回复——"您好像还没说清具体要润色哪句话，也没提身份设定。补充一下，我好接。"——**这句是「润色模型」在说话**：润色提示词里的「身份/风格/关系/当前说话」等锚为空且**没有任何占位说明**时，模型把它当成"用户没提供素材"，转而追要。
- **系统排查结论（全部同类风险点）**：
  - **润色模板（rewrite.template）**：{人格}/{风格}/{关系}/{当前说话} 空时无任何占位说明 → 模型"没提身份设定/没说要润色哪句"；本次症状主因。
  - **接管模板（intercept.template）**：{关系}/{风格} 空与 {上下文}/{记忆} 同类（0.156/0.157 只补了人格/上下文/记忆）→ 一并补齐。
  - **模板损坏**：任一模板被改动/占位符书写异常（如 {说话}、缺右花括号）→ 占位符不替换，模型得到残缺提示词，行为不可预期。
  - **Proactive 模板 / 防抖判定 / 主链放行**：排查无同类风险（内置默认引导完整；判定任务不索要；主链有自己的 persona 兜底）。
- **修复**：
  1. **润色器空态占位**（reply_polish.py）：{当前说话}→"（对方没有说话）"、{关系}→"（你和对方目前还不熟悉，保持礼貌与适当距离。）"、{风格}→"（尚未设定说话风格——自然、干净地表达即可。）"、{人格}→"（暂无角色设定——你就是一位自然、友好、普通的聊天对象。）"。
  2. **润色模板健壮性**：模板无 `{回复}` 占位符 → 末尾强制附录"请润色下面这句（原文）：{原文}"，永远明确"要润色哪句"；模板有 `{回复}` 但替换后仍残留（含未闭合 `{回复`）→ 模板写坏，**回退原回复不润色**。
  3. **接管模板健壮性**：替换后仍残留标准占位符，或模板不含任何核心占位符（{人格}/{身份}/{当前说话}/{上下文}）→ 记录警告并**回退内置默认模板**（DEFAULT_TEMPLATE）重新合成。
  4. **接管模板 {关系}/{风格} 空态占位**（与 2 一致）——0.157 的三类空态（人格/上下文/记忆）扩展为五类（+关系/风格）。
- **诊断日志（本版临时保留）**：接管生成内容（前 120 字）、润色输入 prompt（前 180 字）与输出（前 120 字）——一条消息多 2~3 行日志，定位"模型实际看到了什么"用；确认稳定后撤除。
