# alpha-0.37（2026-08-16）

## 变更

- **按功能细分的多模型配置**：`models.py` + 「模型」选项卡——润色/判定/识图/嵌入/状态/日程/
  主动/梦境/搜索/画像/约定/思考共 12 个功能各配一个模型（下拉，留空回退 AstrBot 默认，
  可重复填同一个；非文本类调用直达对应模型）。
- **回复链路**：`reply_pipeline.py` —— 主链回复后先二次润色，再智能判定（沉默/草草回复/携带表情包），
  表情包以 [EMOJI:分类] 占位符渲染成真实图片；每次调用记账 token，失败安全回退原文。
- **图片识图**：`vision.py` —— 用户图片直连识图模型，智能转述（表情包只说明情绪不啰嗦画面），
  作为图片位置的消息注入。
- **表情包**：`emoji.py` + 「表情包」选项卡——本地图库 + 自定义分类（标题/描述可改）+ 上传；
  判定模型按语境匹配分类后选一张发送。
- **做梦/搜索/思考**：`mind.py` —— 搜索支持 tavily/bing（下拉 + apikey + 结果数），做梦与思考由
  对应模型生成，供状态与主动对话使用。
- **Token 监测**：`token.py` + 「Token」选项卡——按任务/模型/日期记账，总/当天/当月/每模型用量，
  进度条 + 数字展示。
- **配置**：新增 `models`、`vision`、`pipeline`、`emoji`、`search` 五个大类。
- 页面资源版本参数升至 `?v=0.37`。

## 说明

- 独立实现，仅借鉴通用思路，未复刻示例插件代码（雷同扫描 0 处）。
- 回复链路/识图/表情包/搜索均有独立开关；模型留空即回退默认。
- 版本备份：工作区 backup 目录下的 `astrbot_plugin_storyteller_alpha-0.37`。
