# alpha-0.264

## 一、守则：九节，顺序重排

| # | 节 | 作用 |
|---|---|---|
| 01 | `identity` | 我是谁、不是谁、别认错人 |
| 02 | `warmth` | 对她的态度温度 |
| 03 | `tone` | 说话方式（句长/语气词/标点） |
| 04 | `length` | 长度与节奏 |
| 05 | `reference` | 称呼与引用 |
| 06 | `examples` | 好坏对照（专治客服腔） |
| 07 | `format` | 格式禁忌（不用 Markdown 等） |
| 08 | `closing` | 收尾方式 |
| 09 | `tooling` | 工具使用（只在能动手时注入） |

**为什么把 identity 提到第一位**：原来顺序是 `warmth → length → tone → identity`，
模型先读到"多热/多长"再读到"我是谁"，人格锚被稀释。改成
**「我是谁 → 怎么对她 → 怎么说话 → 细节禁忌 → 工具」**的逻辑流。

## 二、面板「守则」页签（你要的交互）

**点击标题展开 → 单独的编辑框 → 停止输入 0.8 秒自动保存**。

- 每节显示序号（就是注入顺序）、中文名、键名、说明、字数；
- 点标题展开/收起，textarea 里是这一节的原文；
- 输入停下 800ms 自动 POST 保存，状态显示「未保存… / 已保存（N 字）」；
- 保存前会把旧文件备份成 `.md.bak`；
- 保存后右上角的字数徽标同步更新。

接口：
```
GET  /astrbot_plugin_storyteller/acting/sections   # 九节列表 + 内容
POST /astrbot_plugin_storyteller/acting/save       # {key, content}
```

## 三、新增占位符 `{守则}`

模板里可以写 `{守则}` 指定守则注入的位置。

**兼容处理（重要）**：

```
模板里有 {守则}  → 在那里替换（你决定位置）
模板里没有      → 自动追加到末尾（老模板行为完全不变）
```

不会因为升级就突然少了一段守则。

## 四、风险与边界

- 自动保存写的是 `plugin_data/.../acting/<节>.md`，不是配置项 —— 所以不会被配置覆盖；
- 保存前备份 `.md.bak`（只留最近一次）；
- 如果 `acting` 目录不存在，`acting_save` 会尝试创建；
- 九节可以整节清空（清空=这一节不注入），但不建议清空 `identity`。
