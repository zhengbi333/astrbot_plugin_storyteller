真机把上一版的三个"已修"全打回了，这版是真正的根因。

## ① 情绪事件一直不生效的真因：属性名写错

`presence.json` 里 `tone` 会动、`last_event` 永远是 `None`。查下来：

```python
self.presence.load()      # ← 根本没有这个属性，是 None
self.presence_store.load()  # ← 真名
```

整个 `_apply_emotion_event` 一直在 `AttributeError` 里打转，被 `except` 吞掉，
所以**看起来"代码在跑"，实际一行都没生效**。

修完后实测：发「你个笨蛋」→ `tone` 从 0.113 → **-0.191**（掉 0.3），发「你好可爱」→ 回升。
关键词判定那层一直是好的（`被骂 / 强度 0.8`），坏的只有落盘那一句。

另外把失败日志从 `debug` 提到 `warning` —— 这类"被吞掉的错"必须能在真机日志里看见。

## ③ mood 兜底（LLM 生成的措辞拦不住）

`presence.sanitize_mood()`：读 mood 时把「收着劲 / 走神 / 心不在焉 / 飘到…」这类
会让她对谁都没兴致的从句整段删掉，只剩中性描述。实测：

- 「快下班了，心思已经飘到菜市场，先松一口气」→「快下班了，先松一口气」
- 「收着点劲等下班，心思飘到买菜」→「此刻心里没什么特别的，正常状态」
