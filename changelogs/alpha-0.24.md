# alpha-0.24（2026-08-08）

## 变更

- **修复「防抖/调试」选项卡切换动画抽动**：
  - 根因：切换动画等待异步页面数据加载完成才播放——点击后先看到「加载中」（无动画），
    数据返回后才播放动画，两段视觉变化造成「卡一下/抽一下」；
  - 修复：`render()` 不再等待异步页面（防抖/设置/调试），各页面先同步填充占位内容，
    切换动画立即播放；数据加载完成后异步填充内容，并附加轻淡入（`.data-in`）避免内容跳变感；
  - 设置页同样补上同步占位（此前内容渲染在数据返回之后，动画期间仍是旧页面）。
- 页面资源版本参数升至 `?v=0.24`。

## 说明

- 版本备份：工作区 backup 目录下的 `astrbot_plugin_storyteller_alpha-0.24`。
