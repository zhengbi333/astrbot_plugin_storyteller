# alpha-0.9（2026-08-08）

## 变更

- **新增页面诊断面板**（左下角常驻，可收起）：
  - 记录页面启动、bridge 就绪、health/外观加载结果；
  - 每次外观变更记录：setAppearance 入参 → 乐观更新 → 重渲染 → POST 发出 → 成功/失败详情；
  - 上传记录：文件选中 → 上传发出 → 成功/失败详情。
  - 用于定位「保存/上传无反应」问题的确切环节（此前后端日志已证明 GET 通、POST 从未到达 handler）。
- **上传按钮恢复 label 方案**（程序化打开文件框在部分 iframe 环境下不弹窗；label 方案此前已验证可弹窗）。
- 页面资源版本参数升至 `?v=0.9`。

## 说明

- 后端不变（alpha-0.8 的请求三级回退已就位）。
- 测试时请关注左下角诊断面板：点击主题后若出现「POST appearance/update 发出/成功/失败」，即可定位问题环节。
- 版本备份：工作区 backup 目录下的 `astrbot_plugin_storyteller_alpha-0.9`。
