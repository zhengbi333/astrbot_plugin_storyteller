# alpha-0.250

真机反馈两件事：**人格不该写死在插件里**、**情绪要被事件推动**。

## 一、人格外置：机制留代码，性格进文件

之前我把「要温柔、要给人笑」这类话写进了守则 —— 那是**测试人格**，不该是插件默认。

现在分清两件事：

| | 放哪 | 内容 |
|---|---|---|
| **机制性** | 代码里（`MECHANICAL_RULES`，5 条） | 不解释模型/提示词、不用 Markdown、不许用「我说话就这样」挡话、不许编造、不确定就说不确定 |
| **性格性** | `plugin_data/<插件>/acting/*.md`（8 节） | 温度、长度、语气、身份姿态、引用、收尾、格式、工具 |

- 每节一个 `.md`，**改完重载即生效**，不用改代码；
- 想换一整套人格 → 改 `acting.rules_dir` 指向另一个目录；
- 临时加口癖 → `acting.extra`；
- 某一节不想要 → `acting.sec_<名字>` 关掉；
- 机制段也能关（`acting.mechanical`，不建议）。

默认文件里的文案已经**中性化**：不再规定她该热情还是冷淡，只写「别让机制压过人格卡」
「对方说你冷时按人格卡调整，别用『我说话就这样』堵回去」。

**功能一个没删**：`build_guidance` / `preview` / 分节开关 / `extra` / `rules_dir` 全在，
`max_chars` 默认仍 800。

## 二、情绪事件驱动：被骂一句立刻有反应

之前的情绪靠时间慢慢漂，被骂也只会「嗯」。现在两段式判定：

1. **关键词秒判**（零延迟、不花钱）：吵架/被骂/被嫌弃/被冷落/被夸/被表白/被撒娇/被关心
   八类，命中立刻改状态。强度按用词激烈程度 + 标点放大。
2. **LLM 兜底**（`emotion.use_llm`，默认**关**）：关键词没命中、但句子带隐含情绪
   （讽刺、冷淡）时再判一次。有日额度（默认 200），失败一律降级为「无事件」。

增量示例（强度 1.0 时）：

| 事件 | tone | tempo | battery |
|---|---|---|---|
| 吵架 | -0.44 | +0.20 | -0.10 |
| 被骂 | -0.38 | +0.10 | -0.06 |
| 被表白 | +0.34 | +0.14 | +0.04 |
| 被夸 | +0.28 | +0.10 | +0.05 |

时间演化仍在，但只负责"慢慢回归中性"；**事件优先**。

## 四、已知边界

- 关键词是**字面匹配**：「你一点都不讨厌」也会命中「讨厌你」→ 可能误判，所以强度不会打满；
- LLM 兜底默认关（省钱），要更准就打开；
- 图文割裂、撤回、`relationships.json` 0KB 这三件仍未做，排在下一轮。
