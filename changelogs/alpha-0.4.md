# alpha-0.4（2026-08-08）

## 变更

- **顶部导航棱角化**：整体圆角体系由「胶囊/圆形」改为方角（10px 主、8px 控件、1px 滑块轨道），
  色票、颜色块由圆形改为方形，贴合「简约棱角分明的科技风」。
- **修复上传背景图无反应**：
  - 根因：文件选择框使用 `hidden` 属性（`display:none`）+ 程序化 `.click()`，在 iframe 环境下点击被静默忽略；
  - 修复：改为 `<label>` 原生关联文件选择框（点击按钮即打开系统选择器），输入框用 1px 视觉隐藏（保留可点击性）；
  - 顺带修复：背景效果总开关统一为 `canvas_enabled`（此前前端读 `bg_enabled` 字段，后端从未返回，导致背景图即使上传成功也不显示）；上传成功自动启用背景。
- **修复滑块进度条定格**：
  - 根因：进度填充使用 `var(--fill, 60%)` 但从未被赋值，条默认定格 60%；
  - 修复：渲染时按当前值计算 `--fill`，拖动时同步刷新（透明度按 0-100%，模糊按 0-60px 归一化）。
- **背景板交互完善**：
  - 未开启时颜色与滑块控件整体置灰并提示「开启后生效」；颜色仅在开启时应用到底色；
  - 主色/辅色/背景色三个字段新增「恢复」按钮，一键回到跟随主题（文本框清空同样支持）；
  - 开关文案明确：背景板已开启 / 已关闭。
- **修复外观保存后背景图闪失**：后端 `appearance/update`、`appearance/reset` 响应统一附带背景图 data URL（与读取接口一致），前端保留本地缓存双保险。

## 说明

- 外观存储与后端 API 结构不变，已有配置兼容。
- 版本备份：工作区 backup 目录下的 `astrbot_plugin_storyteller_alpha-0.4`。
