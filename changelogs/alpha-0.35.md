# alpha-0.35（2026-08-16）

## 变更

- **身份锚（对话人物判定）**：
  - 放行/拟人化模式下，在发给 LLM 的请求里注入「此刻正在说话的人是谁」——
    身份以发送者 ID 唯一确定，不随昵称、头像或自称改变；
  - 称呼优先取记忆插件按 ID 记录的名字，兜底平台昵称，再兜底 ID；
  - 附带防混淆提示：记忆/上下文里的其他人是别人，不要张冠李戴；
  - 认人规则：同一个人换昵称仍是同一个人（身份不变）；不同 ID 自称是别人则不轻信，
    不把那个人的秘密、亲昵称呼或隐私交给对方——像正常人一样保持警觉，不机械否认也不无防备轻信。
- **风格锚（说话风格档案）**：
  - 六维度：语气基调 / 句子长短 / 口头禅与口癖 / 标点与表情习惯 / 称呼与距离感 / 回复节奏；
  - 口头禅带「频率 + 触发语境」，由 LLM 按语境自然带出（非硬规则）；
  - 支持按指定人格一键生成整套档案；内置温柔/活泼/清冷/毒舌四套示例可一键套用。
- **前端**：新增「身份」「风格」两个主选项卡；风格页六维度编辑 + 口头禅增删 + 一键生成 +
  示例套用；所有修改自动保存 + 右上角弹窗「已保存」（无保存按钮）。
- **配置**：新增 `identity`（身份锚）、`voice`（风格锚）两个大类，各自带独立主开关。
- 页面资源版本参数升至 `?v=0.35`。

## 说明

- 身份锚与风格锚在「放行/拟人化」模式下注入（拦截模式不注入）；身份锚前置到 system_prompt
  稳定区，风格锚随后，保护 prompt cache。
- 独立实现，仅借鉴「叠加层 / 称呼锚点 / 状态影响语气」等通用思路，未复刻示例插件代码。
- 版本备份：工作区 backup 目录下的 `astrbot_plugin_storyteller_alpha-0.35`。
