## 当天日程转盘样式修复（可读性）

- `.sched-time`（时间段）：13px 浅灰 → **14px 加粗、`--ink-2` 色**；此刻条目时间用青绿强调色；
- 备注 `.sched-line .hint`：12.5px 浅灰 → **13.5px、`--ink-2` 色**；此刻条目备注用主文字色；
- 前后虚化条目 opacity 0.45 → 0.68（仍保留"虚化"语义但可读）。

## 新增设置项「生成预算上限（max tokens）」（models.stream_max_tokens）

- 之前 max_tokens 是写死在各调用点的内部值，用户看不到也调不了；现在做成设置项
  （设置 → 模型配置 → 生成预算上限，默认 4000，hint 已写明利害与语义：
  保险丝不是速度旋钮，正常生成自然收尾绝不截断，只有跑飞才硬截断）。
- `chat_text` 未显式传 `_max_tokens` 时读该全局默认；调用点覆盖仍生效（衣柜 6000）。

## 衣柜页：与「当前穿搭」换位 + 分页

- 布局调整：**中栏（大空间）= 衣柜**（标题 + 一键生成衣柜 + 分页列表 + 添加衣物）；
  **左栏 = 当前穿搭**；右栏 = 设置。衣柜获得最大显示空间。
- **分页**：10 件/页，「第 x/y 页 · 共 N 件」+ 上一页/下一页；翻页只重渲列表局部；
  删除/添加后自动回到有效页码；空衣柜提示引导点击右上角按钮。

## 调试页新增「运行时 Provider 诊断」

- `GET diag/runtime`：进程内真实值——工作目录、数据目录、配置路径、
  各提供商运行时状态（模型/超时/Key 长度与**尾号**/base）。
- 用途：核对"面板保存的 Key 与 cmd_config.json 文件是否同步"（面板测试与插件
  直连都走运行时内存配置；文件可能滞后——重启后可能回退旧值，可在此一眼确认）。
