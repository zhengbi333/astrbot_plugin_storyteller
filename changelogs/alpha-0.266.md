# alpha-0.266

## 我把它弄坏了

0.265 修「切页内容不换」时，我用正则批量给 29 处渲染调用加了 `await`。
正则还**误改了一段回调函数里**的调用：

```js
apiGet("memory").then((d) => {
  if (state.current === "memory") await renderMemory();   // ← 非 async 箭头函数里不能 await
}).catch(...)
```

`await` 在非 async 上下文里是**语法错误** → 整个 `app.js` 解析失败 →
**什么都不执行** → 面板白屏（只剩静态头部）。

## 修了什么

把那一处改回同步调用。现在 `node --check` 通过。

- **D** 专门查 `.then((x) => { ... await ... })` 这种**非 async 箭头函数里裸 await**（就是我这次犯的错）。

**从此改前端必须过这一关。** 生产环境不会告诉你哪行错了，只会白屏。
