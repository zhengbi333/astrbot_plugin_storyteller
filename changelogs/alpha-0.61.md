# alpha-0.61 —— 身份页：总开关左侧 + 「{身份}」注入内容编辑器

> 「身份」标签页按需求改造：总开关在左侧，右侧为可编辑的「身份锚注入内容」（即 {身份} 占位符被取代后的文本），修改后保存生效。智能判断上下文方案待用户决策（见 alpha-0.62 计划）。

## 新增

- **身份页「{身份}」注入内容编辑器**：
  - 布局：左侧总开关（身份锚 on/off），右侧编辑区（textarea + 保存按钮 + 「载入最近生成」）。
  - 编辑区显示/编辑每次注入 LLM 的「身份锚」文本；留空 = 自动生成（判定人物/称呼/防张冠李戴规则），填写 = 此后固定使用这段内容。
  - 「载入最近生成」把最近一次**实际自动生成**的身份锚缓存填入编辑框（便于查看/改造）。
- **后端**：`identity.custom_text` 配置键（覆盖自动生成）；`_build_identity_anchor` 配置优先 + 缓存最近自动生成；API `GET /identity/editor`（返回 custom / 最近自动生成 preview）。
