# alpha-0.20（2026-08-08）

## 变更

- **设置页改为「模块子选项卡」布局**（对齐「为你篆刻的历史」的分类浏览体验）：
  - 设置页顶部为各功能大类（模块）的次级选项卡（当前为「基础」，后续新增功能选项卡时对应新增大类）；
  - 点击切换模块，当前模块的设置项一目了然；
  - 每个设置项：醒目标题（15px 加粗）+ 字段键名小标 + 说明小字 + 分隔线分组，替换原先过小的选项标签。
- **开发约定（已记录）**：此后每新增一个功能选项卡，必须在设置中单独建立对应大类，并包含该功能的总开关。
- 自动保存、「已保存」提示、动画设置等行为不变。
- 页面资源版本参数升至 `?v=0.20`。

## 说明

- 版本备份：工作区 backup 目录下的 `astrbot_plugin_storyteller_alpha-0.20`。
