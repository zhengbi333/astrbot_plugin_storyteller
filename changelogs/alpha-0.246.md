# alpha-0.246

## 一、新增「扮演守则」：把"怎么演"从模板里分出来

之前的 system 里有三层：**人格卡**（我是谁，用户提供）→ **拦和改模板**（上下文怎么装配，用户定制）
→ **任务守则**（怎么用工具）。但"怎么演"这件事一直没有独立位置：

- 塞进模板？会覆盖用户精心写的模板（有的只有 250 多字）；
- 塞进人格卡？人格卡只该管人设，不该管"引用怎么处理"这种协议细节。

所以新增独立一层：`acting.py` + `acting.*` 配置，在 system 末尾追加一段【怎么演】。

### 它管什么（每条都是可执行动作，不是形容词）

| 分节 | 内容举例 |
|---|---|
| 句子长度 | 默认一句话、最多两句；能用「嗯」「草」就不用整句；一条只说一件事 |
| 语气 | 不用「首先/其次/另外/总之」；不复述对方的话；不升华不给建议；不解释自己刚说的话 |
| 身份应对 | 被问是不是 AI 就大方承认，但用群友方式接，不解释模型/提示词/上下文 |
| 引用与 @ | 引用她自己的话必回；引用别人的话不抢话；被 @ 或叫名字必回 |
| 收尾 | 不想接就安静，或用「我先去忙了」收尾，不写括号内心戏；不必每轮以问句结尾 |
| 格式 | 不用 Markdown；情绪靠标点和词；表情包/戳一戳偶尔用 |

### 配置

- `acting.enabled`（默认**开**）：一键关掉整段；
- `acting.max_chars`（默认 900，夹 200~2000）：这段每轮都带，太长费 token；
- `acting.sec_length / sec_tone / sec_identity / sec_reference / sec_closing / sec_format`：
  六个分节可单独关（比如你的人格卡已经写死了语气，就关掉 sec_tone）。

## 二、为什么不是"直接改模板默认值"

模板是用户的（你现在那份是 250 多字的自定义版）。改默认值只影响新装机，对你无效；
而独立一层**立刻生效、随时可关、不覆盖模板**，是更合适的做法。

## 三、验证

`_st_test/audit_67_acting.py` —— **22/22**：

- 默认内容包含 6 类规范（长度/不解释/引用/@/Markdown/不总结）；
- 总开关关闭 → 空；关掉引用节 → 该节消失但其它还在；六节全关 → 空；
- 字数上限生效（200 夹紧、超限截断带标记、上限夹到 2000）；
- system 里确实追加（`final_system += "\n\n" + _acting`）且有异常兜底；
- 与任务守则【工具与任务】并存、互不覆盖；
- schema 默认值正确。

## 四、已知边界

- 守则只管"怎么演"，**不管人设**；两者冲突时以人格卡为准（守则里没有身份设定）。
- 它每轮都随 system 发送，`max_chars` 是成本护栏，别调太大。
- 还没做"按场合切换守则"（群聊/私聊同一套）。
