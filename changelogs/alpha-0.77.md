# alpha-0.77 —— 状态模块：心绪三表 + 心事 + 互动涟漪 + 语气走廊 + 节拍演化 + 时间底色

> 采用原创「这一刻的你」模型（不在维度和“生理仪表盘”上直接照搬示例）：心绪用调子/转速/电量三个直觉表；
> 心事（心里飘的）与互动涟漪（刚那话还没完全出来）；语气走廊只给语言不给数值；演化用节拍而非每秒衰减。

## 新增 / 变更

- **心绪三表**：`tone`（低沉↔轻快）`tempo`（慢↔急）`battery`（亏↔满）；兼容旧 valence/arousal/energy 数据自动迁移。
- **心事 Wander**（≤3）：演化浮现、按节拍随时间淡出；注入时作为"心里还挂着…"。
- **互动涟漪 Ripple**（≤3）：有重量的互动（分享/求助/道谢/争执）事件染色 + 留一句余光；可开关 `ripple_enabled`。
- **语气走廊 Stance**：读取时同步合成（心绪+心事+时间底色），`{状态}` 注入**只给语气走廊 + 一句心情**，不给数值。
- **时间底色**：深夜/清晨/白天/傍晚 + 赴约前 → 背景光影响语气（非闸门），可开关 `time_bg_enabled`。
- **节拍演化**：自动演化默认**关**（升级后不自动调模型）；开启后按 `beat_interval`（默认 30 min）像人一样缓过来；手动「一键生成」`POST presence/evolve` 共用同一后端；失败驳回本次跳过。
- **页面三栏**（遵循三栏偏好，全卡片）：左＝此刻（三表/心情/心事/涟漪）；中＝演化（一键生成 + 语气走廊预览 + 手动微调三表重算走廊 + 节拍记录）；右＝状态设置（总开关/自动演化/节拍/天气/状态模型/时间底色/涟漪）。
- 注入仍坚守"只改语气长短节奏、不降理解质量"；与示例/常见实现的差异：不是生理维度仪表盘、不是每秒衰减、不是"睡眠闸门"，而是直觉表 + 节拍 + 叙事层。

## 逻辑链（模块化、互不依赖、低耦合）

- 数据：presence.json（纯数据）。
- 唯一 LLM 来源 = 自动演化（状态模型直连，节拍可配，failure 跳过）；染色（_apply_emotion_impulse→presence.stain）、节拍冲刷（tide）、语气走廊（compose_stance）全部同步纯函数；
- presence 只读日程（时间底色，单向只读），不依赖记忆/防抖/拦截，也不被它们依赖；注入路径 0 额外 LLM 调用。
