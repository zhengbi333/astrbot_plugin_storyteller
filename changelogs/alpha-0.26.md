# alpha-0.26（2026-08-08）

## 变更

- **修复消息防抖不生效**：
  - 根因：防抖管理器在插件初始化时持有 `ConfigView` 快照，而设置页保存配置时会**重建** ConfigView
    （`plugin.config = ConfigView(raw)`）——防抖管理器始终读取旧配置对象，`enabled` 永远为 False，
    表现为「总开关已打开但防抖选项卡显示未开启、实测无效果、日志无提示」；
  - 修复：防抖管理器改为持有插件引用、**每次动态读取当前配置**，设置页保存后立即生效
    （LLM 请求拦截直接读 `self.config`，无此问题）。
- 页面资源版本参数升至 `?v=0.26`。

## 说明

- 专项验证：配置保存后防抖开关动态生效。
- 版本备份：工作区 backup 目录下的 `astrbot_plugin_storyteller_alpha-0.26`。
