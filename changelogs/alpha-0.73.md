# alpha-0.73 —— 人格模块：{人格} 注入体 + 一键生成 + AstrBot 人格库选择

> 解决「人格提示词内容缺失」：新增独立「人格」选项卡（风格之后），把 AstrBot 人格/设定整理成一份
> {人格} 注入体（身份背景、世界观等），注入最终信息格式，接管两种模式都不再丢人格。

## 新增 / 变更

- **「人格」选项卡**（在「风格」之后，选项卡 16 → 17）：三栏布局
  - 左＝一键生成（AstrBot 人格库选择 → 自动填入描述框 → 一键生成并自动保存）
  - 中＝**人格注入体编辑**（{人格} 占位符内容，可直接改；「清空」后回退 AstrBot 当前默认人格）
  - 右＝人格设置（总开关 + **人格生成模型**下拉 + 说明条）
- **占位符 `{人格}`（共 14 个）**：默认模板开头加入「【你的身份】{人格}」段；
  注入内容优先取已保存的人格注入体，为空时兜底 AstrBot 当前默认人格 prompt（异步读取，勿缺）。
- 分工明确：**人格管「身份背景」（叫什么/身世/世界观）**，风格管「说话方式」——人格提示词不再"只出六维"而丢内容（与示例插件同思路：人格本体保真注入）。
- 后端：`persona_profile.PersonaStore`（persona_injection.json）+ `persona.enabled/provider_id` 配置 + `persona_gen` 直连模型键；
  API：`persona/read` `persona/update` `persona/generate` `persona/personas`。
