# alpha-0.271

## P0-3 试运行（只演不发）

打开 `simulation.enabled` 后：**防抖、记忆、情绪、工具选择、生成全部照跑，最后一步不真的发到 QQ。**

用途：安全观察她到底会怎么回、会不会调工具，而不打扰任何人。

## 三个出口全部收口

| 出口 | 位置 | 试运行行为 |
|---|---|---|
| 超时兜底直发 | `main.py` `_send_timeout_reply()` | 记录「本应发什么」，不调 `event.send` |
| 生图发送 | `main.py` 生图分支 | 记录图片路径 + caption，返回 False（交回主链照常回话） |
| 回复缓冲（主出口） | `reply_buffer.py` `_send_item()` | 记录完整 chain，标记 `sent`，返回 True |

**生图那一支特意返回 False**：试运行时不该因为"图没发出去"就把整轮对话吞掉。

## `_diag.log` 里长这样

```
[试运行] 本应发到 qianran:FriendMessage:10001：稍等，我这边卡了
[试运行（生图）] 本应发到 ...：[Image:img_1793103819988.png] | 给你画好啦～
[试运行（回复缓冲）] 本应发到 ...：好呀，那我们去看看
```

`_preview_chain()` 会把 MessageChain 压成一行（文字原样、图片显示文件名）。

## 认知侧：写操作「只演不做」

`toolbox_fs_write` / `doc_write` / `python` / `shell_run` / `edit` / `archive`
六个工具在试运行下返回：

```
（试运行，未执行）写文件：现在只演不做，关闭试运行后会真正执行。
```

这样你能看到"她想写哪个文件、写什么"，但磁盘不会被改。

## 已知边界

- 试运行**不拦记忆写入**（她照样会记住你说的话）—— 这是有意的：记忆不属于"对外发送"；
  如果你希望试运行时也完全不写记忆，需要再加一个开关，本轮没做；
- 试运行**不影响她已经发出的消息**，只影响之后的新消息。
