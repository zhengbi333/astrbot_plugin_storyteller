# alpha-0.66 —— 新增「接管走主链」模式

> 应您的要求：在「接管改换」（直连）之外，新增「接管走主链」——把模板写进主链即将发给 LLM 的请求并放行，回复走主链管线。

## 新增

- **介入方式新增「接管走主链」**（模式共 5 种：监视 / 放行 / 阻断 / 接管改换 / 接管走主链）：
  - 主链来请求 → 拦截并把 `req.system_prompt` 替换为模板合成结果（含全部占位符、{记忆} compose 记忆包）、`req.prompt` 改为引导句
  - **不 stop、放行主链** → LLM 回复走主链正常管线：`on_llm_response`（记忆插件记录 Bot 回复、二次润色、表情包渲染）、主链会话历史全部自动生效
  - 模型使用**主链默认模型**（不再需要独立的「接管改换模型」；接管改换仍是直连指定模型）
- 默认介入方式仍为「接管改换」。

## 测试

- `smoke_story_takeover.py` 72 项（新增：模式解析、接管走主链端到端——req.system_prompt 为模板合成、req.prompt 引导句、不 stop、不直连、快照 mode=接管走主链）
- 全量回归 + 部署差异 0
