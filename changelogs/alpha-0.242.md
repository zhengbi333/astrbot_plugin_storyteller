# alpha-0.242

## 一、短回复不再润色（治"不像人"的一处硬伤）

润色是**第二个模型在重写**。它的模板里只有 `{人格}/{风格}/{状态}/{关系}/...` 这几个占位符，
**看不到人格卡里的「AI 味黑名单」与"1~10 字"铁律**；对「草」「行」「6」这种 1~2 字的群友腔，
它几乎一定会扩写、升华、加语气词 —— 越润越假。

本版加了一道闸：

- `rewrite.skip_short_enabled`（**默认开**）：回复长度 ≤ 阈值就**跳过润色**，原样发出；
- `rewrite.skip_short_chars`（默认 **12**，夹在 1~40）：短句阈值，覆盖绝大多数群友腔；
- 长回复照常润色（润色对长文本仍有价值：顺句子、去掉多余的客套）。
- 跳过时走 `logger.debug`，不影响面板里"最近发给 LLM 的内容"。

## 二、外部工具描述改为一次取用 + 短时缓存

0.241 引入外部工具桥后，`get_func_desc_openai_style()` 在一轮里会被问**两到三次**
（组装 tools 一次、tool loop 里算工具名一次；MCP 工具多时开销更明显）。

本版合并为 `_astrbot_tool_bundle()`：

- 一次调用同时拿到「工具描述」与「工具名集合」，同一轮共享；
- 缓存键 = `(启用状态, 白名单集合)`，配置一改就失效；
- TTL **20 秒**：容忍 MCP 运行时热插拔（新挂上的 server 最迟 20 秒后可见），又不至于让缓存变陈旧；
- 拿不到工具管理器、读取抛异常时**安全返回空**，不影响主流程。

## 四、说明

- 这两个改动都**不改变工具能力**，只改"什么时候不做事"，所以风险面很小；
- 短句闸**默认开**是我替你做的判断：你反复提到的"不像人"里，短句被扩写是最刺眼的一种。
  如果你更喜欢全部润色，把 `rewrite.skip_short_enabled` 关掉即可。
