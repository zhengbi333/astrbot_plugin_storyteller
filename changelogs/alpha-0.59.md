# alpha-0.59 —— 设置项卡片化（全局「展示板」规则）

> 补上既定规则：**每一个设置项都要是一张与背景区分的「展示板」卡片**（参考「防抖」标签页）。
> 上一轮「拦＆改」页的拦截设置渲染成了无背景的裸字段，且「拦截参与总开关」下方留白过多，本版统一修正。

## 变更

- **renderSettingField 统一卡片化**：所有设置项（布尔开关/介入方式选项/模型下拉/整数/文本）由渲染函数自动包成 `.setting-card`（背景 + 边框），
  设置页各子选项卡、各模块页「模型设置」小节、拦＆改页拦截设置、防抖页设置全部生效——每个设置项都是一块可辨识的展示板。
- **总开关改用防抖同款大卡**：「拦＆改」页「拦截参与总开关」改为 `.master-switch`（大号红色开关 + 标题 + 说明，与「防抖总开关」同一卡片样式），
  下方「介入方式 / 记录条数 / 接管改换模型」各自成卡，消除总开关下方大段空白。
- **去重复卡片**：防抖页「防抖总开关」移除多余的外层卡（`.master-switch` 本身即卡片）；防抖设置每项保持单卡。
- **展示面板背景板**：「拦＆改」页「LLM 请求拦截」「用户当前请求」「最终发送给对话 LLM 的信息格式」「最近发送给对话 LLM 的内容」四块展示区改用防抖同款 `.panel` 底板（背景 + 边框 + `.panel-head` 标题行），与防抖页面板统一，不再是透底的无框区域。
- 卡内 `field` 紧凑排版：标题 14.5px、无报表式分隔线，卡片间距由网格 gap 控制。
