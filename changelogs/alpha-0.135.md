# alpha-0.135

## 嵌入模型严格模式 + 清障页三栏/依次真实 LLM 测试（0.134 验收反馈）

- **嵌入模型不再有任何回退**（你要 1）：`resolve_embedding_provider` 改为严格模式——
  只使用明确配置的嵌入分类 provider；未配置或无效直接驳回并输出报错日志（不再自动
  挑选第一个可用嵌入 provider，也不参与「留空回退模型」——回退模型来自对话 LLM，类型不匹配）；
  嵌入下拉首项文案区分为「未设置——调用将报错」。
- **清障页重构**（你要 2）：
  - **三栏布局**（窄屏自动降 2 栏/1 栏）；
  - **LLM 项默认不测试**：清障清单改为「定义模式」——打开页面只列出全部 32 项（16 只读 +
    15 LLM + 下游客户端），LLM 项显示灰色「未检测」，**只有点击每个模块的「测试」才执行**；
  - 原「一键全部测试」更名**「一键只读测试」**（只测 16 项内部 + 下游客户端，不含 LLM）；
  - 新增橙色**「一键 LLM 测试」**：**依次（串行，非并发）**真实 ping 全部模型——
    不再是零调用探测，而是**真实最小对话**（「请只回复：OK」，每模型一次极短生成，
    少量 token 消耗）；单个失败/超时精确点名（模型名 + 原因 + 耗时）；
  - **超时时间在本页设置**：新增「清障」配置大类 `troubleshoot.llm_test_timeout`
    （默认 15 秒，5–120 可配，修改即保存），「一键 LLM 测试」与单项测试都受它约束。
- 回归：smoke_troubleshoot 24 项重写（定义 32 项/串行顺序/超时/报错/配置失效/回退兜底/
  路由 17+15 项/下拉分类）；verify_057 141 项（清障页断言改为定义模式 + 双按钮 + 超时设置）。
