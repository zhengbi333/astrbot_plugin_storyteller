# alpha-0.200

## 能力工具化 · 阶段 3：预检测收敛为兜底（消除双重执行）

阶段 1/2 让模型能主动做事（文本协议 + 原生工具），但**插件自己的关键词正则仍在抢着做同一件事**（"记住"类话术、日程调整意图、搜索意图），可能造成双重执行（模型调了工具 + 正则又做一遍）。本版把正则收敛为**兜底**。

### 收敛规则（`capabilities.suppress_regex_fallback`，默认开）

**工具可用时**（`capabilities.enabled` + `native_tools` 且**未被提供方拒绝过**）→ 抑制同类正则预检测：

| 预检测 | 收敛后行为 |
|---|---|
| `_write_commitment`（"记住/约定"话术 → 写记忆） | **接管链路同步写入 + 观察层后台写入都跳过** → 交给模型的 `memory_write` 能力 |
| `_detect_plan_intent` → `_auto_plan`（"明天三点叫我" → 改日程/穿搭） | 跳过 → 交给 `schedule_edit` / `outfit_change` |
| 会话搜索（"帮我搜一下…"） | **保留**（明确指令、正则确定命中、比多一次模型往返更省）→ 执行后登记 `caps_done("web_lookup")`，**构建工具清单时移除 `story_web_lookup`**（模型不会再搜一遍） |
| 生图硬信号（"拍个照发我"） | **保留**（零延迟体验最好；生成后直接阻断，不存在双重） |
| 表情包判定 / 沉默判定 / 润色 | 非预检测，保持（表情包已有 `caps_done` 去重） |

### 自适应恢复（关键安全设计）

- `_generate_once` 捕获提供方拒绝 tools（HTTP 400/422）→ **置位 `_native_tools_unsupported`** → 本进程内**自动恢复全部正则兜底**（`_suppress_regex()` 返回 False），并记日志。
- 也就是说：**提供方不支持原生工具时，行为自动回到阶段 1 之前的正则路径**，用户无需改配置；也可手动关掉本项。

### 精准去重（`build_tool_schemas(exclude=...)`）

- 本轮正则兜底已完成的动作（如搜索）会登记到事件上 → 该能力**不再出现在模型本轮的工具清单里**（从源头避免重复，而不是执行后补救）。
