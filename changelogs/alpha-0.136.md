## 嵌入下拉文案 + 清障「记忆 · 嵌入模型」+ 下游客户端连接级检测（0.135 验收反馈）

- **嵌入下拉空项文案修正**（你要 1）：嵌入/重排字段空选项不再显示「按『留空回退模型』策略」，
  改为「未设置——调用将报错」（聊天类字段保持原策略文案）——与严格模式的实际行为一致。
- **清障新增「记忆 · 嵌入模型」测试项**（你要 2）：真实连通性——对「记忆测试」做一次
  `get_embedding`（少量消耗、受超时约束），显示模型名 + 耗时 + 向量维度；
  未配置 → 红提示「嵌入模型未配置（嵌入不走留空回退模型；请到记忆页选择嵌入分类下的模型）」；
  配置无效/超时/空向量均精确点名。纳入「一键 LLM 测试」依次串行范围（现 16 个 LLM 项）与单跑。
- **下游客户端改为连接级检测**（你要 3，找到真机制）：AstrBot 的 `Platform.status` 只表示
  适配器生命周期（启动/错误），不代表 NapCat 是否连上——真正的一手连接状态在 aiocqhttp 的
  CQHttp 里：`_wsr_api_clients`（反向 WS 客户端 dict）与 `_wsr_event_clients`（set），
  **连接建立时写入、断开时移除**（实锤 aiocqhttp 源码）。现对 aiocqhttp 平台读数：
  非空 → 「NapCat 已连接（N 个 OneBot 客户端）」；空 → 红「已启动但未检测到 OneBot 连接
  （NapCat 等未连接）」——你没开 NapCat 时它会如实变红；其它平台退化为
  「已启动（无连接级指标）」并注明。
