# alpha-0.153

## 衣柜预览「应用一件其余消失」修复（用户反馈）

- **根因**：点「应用」后调用整页重渲染 `renderWardrobe()`，而预览数组是函数内**局部变量**——重渲染时被重置为空，其余预览随之消失。
- **修复**：预览状态提升到全局 `state.wardrobePreview`；renderWardrobe 每次渲染从全局恢复预览并重新绑定逐件按钮；「应用」「删除」都只操作全局预览，重渲染不再清空。
- **回归**：verify_interact 新增穿搭页交互断言——生成 3 件预览 → 应用第 1 件（`wardrobe/apply_batch` 单件、其余保留 B/C、A 消失）→ 删除剩余 1 件（只剩 C），**51/51**（+4）；057 169 / 046 31 / **41 项冒烟 0 失败**。
