# alpha-0.204

## 思绪（内心持久化）：让 Bot 拥有连续的内心线

**起因**（用户观察）：观摩其他 Bot 时发现它们能"思考内容持久化"——上一轮心里想过什么，下一轮还记得。我们的 Bot 只记得**自己说出去的话**（在上下文里），却不记得**自己想过什么**：直连流式里的 `reasoning_content` 仅用于"思考风暴早停"与 token 记账，从不保存也不回注，内心线是断的。

### 先做可行性实测（不改代码，真实 DeepSeek）

| 实验 | 结果 | 结论 |
|---|---|---|
| 关闭思考调用 | 0.4s，`reasoning` 0 字 | — |
| 开启思考调用 | 1.5s（延迟 3.72 倍），`reasoning` **仍 0 字** | ❌ 直接保存模型思考在本模型上**不可行** |
| 回复内隐藏块 `<思绪>…</思绪>`（20 次 × 5 类话题） | **闭合规范 20/20 = 100%**、未闭合泄漏 0/20、可见部分干净 20/20、平均 0.75s（与不加完全相同） | ✅ 可行 |
| 第二轮注入上一轮隐藏内容 | 回复走向明显不同 | ✅ 有效 |

**防雷同**：参考插件密集使用"念头"（主动念头池/脑内念头）与 `persona_inner_voice_prompt`（"内心活动风格"）。本实现**改用自有措辞**——模块名「**思绪**」（用户命名）、隐藏块 `<思绪>`、注入段"你上一轮的思绪/藏起来的那半句"，并在 `mindstream.py` 头部写明独立性声明（产出方式、数据结构、回注策略、配置键均为自有设计，与外部插件的候选池/风格配置/日记文体在目的、载体、数据上均不同）。改名后重测：遵守率 **20/20 = 100%**（旧名 95%）。

### 机制：产出 → 剥离 → 留档 → 回注

```
生成（system 追加"藏起半句"指令）
  → 【生成后立刻剥离】：可见文本 & 藏起来的那半句 分开
       · 可见文本 → 原链路（能力解析 → 沉默判定 → 润色 → 表情包 → 发送缓冲）
       · 藏起来的那半句 → MindStore.inner 留档（时间/会话/对方那句/可见回复/思绪/心情快照）
  → 留档（放在判定之前：即使这轮判定沉默、什么也没发出去，它的思绪照样留下）
  → 下一轮注入【最近 N 条同会话思绪】= 继续想下去的起点
  → 发送前再摘一次保险（任何分支都不可能把藏起来的内容发给对方）
```

| 设计点 | 取值 |
|---|---|
| 回注条数 | 默认 **1**（`mindstream.inject_count`，0-5；先用 1 观察是否显得反复咀嚼） |
| 留档条数 | 默认 30（`keep`，1-200，超出丢最旧） |
| 单条回注上限 | 默认 120 字（`inject_max_chars`，超出截断） |
| 未闭合兜底 | 默认开（`strip_unclosed`：模型漏写结束标记时把起始标记之后整段摘除，绝不外泄） |
| 跨会话 | **不串**（同会话才回注，避免群里的心事带进私聊） |
| 去重 | 已回注过的条目不再回注；超过 60 条记账自动重来一轮 |
| 开关 | 独立主开关（`mindstream.enabled`，默认开，可一键关） |

### 新「思绪」主标签页（NAV 中位于「内心」之前）

- **左栏**：思绪总开关（红色滑块）+ 留档总数 / 今日新增 / 回注条数 / 留档上限 + 说明
- **中栏**：思绪留档流（每条：时间 · 心情 + **藏起来的那句** + "说出口的是…" + "那时对方说…" + 删除按钮），分页 6 条/页
- **右栏**：设置项（留档条数 / 回注条数 / 单条上限 / 未闭合兜底），走统一的设置渲染与保存
- 设置页**不重复展示**（该模块有专属页）；接口：`GET mindstream`、`POST mindstream/delete`

### 顺带修掉两个真 bug（测试发现）

1. 留档时引用了不存在的变量名（`text`）→ 改为 `event.message_str`；
2. 回注记账被"这轮有没有写思绪"的 `if` 包住 → 某轮模型没写思绪时，上一轮条目永远记不上账、去重失效（已解耦为独立记账块）。
