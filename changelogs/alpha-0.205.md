# alpha-0.205

## 两个新能力：`inner_recall`（回想思绪）与 `manage_todo`（待办）

承接 0.204 的思绪留档——本版让模型**能主动用**这份留档，并把"要做的事"变成可勾选的待办。

### ① `inner_recall`：回想自己当时的思绪（P0）

- 走既有能力注册表（与 11 个能力同构）：参数 `query`（可选关键词）、`count`（默认 3）。
- **同会话优先**：先翻当前会话的留档；本会话还没有则退回全体（"我最近都在想什么"也说得通）。
- 支持关键词过滤（按思绪内容/对方那句/可见回复三处匹配）；命中不到时**如实说想不起来**，`next_hint` 明确"别编一个"。
- 主链同名工具 `story_inner_recall`；每日限额 `capabilities.inner_recall_daily`（0=不限）。

### ② `manage_todo`：待办（记 / 完成 / 列）（P1）

**与「记住」的分工**（用户要求"不另起一套"）：
- **`add`**：内容照样写进**既有长期记忆通道**（`memory_type=note`，长期可检索）——语义与"记住"一致；
- **本地只补记忆库没有的信息**：**完成状态**（可勾选），存 `MindStore.todos`（复用同一个 `mind.json` 与读写逻辑），条目含 `{id, text, done, at, done_at, session, memory_id}`；
- **`done`**：按关键词或 id 把最近一条未完成标记完成；找不到时**如实说没找到**（不硬说做完了）；
- **`list`**：默认只列未完成，可选含已完成（显示 `√`）；
- **诚实边界**：记忆库写入失败时，本地待办照样建立，但 `next_hint` 会标注"（写长期记忆失败：…；只记在了待办里）"——**不让模型谎称"都记好了"**。
- 主链同名工具 `story_manage_todo`（`action` 带枚举）；每日限额 `capabilities.manage_todo_daily`（0=不限）；本地最多留 200 条。
