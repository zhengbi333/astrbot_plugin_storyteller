# alpha-0.29（2026-08-08）

## 变更

- **命令消息识别加固与诊断**：
  - 文本提取增加多来源兜底（`event.message_str` → `get_message_str()` → `message_obj.message_str` → 组件 Plain 文本），
    避免因某来源为空导致命令被误判为普通消息；
  - 命令判定前后增加日志（`防抖判定非命令: text=...` / `防抖遇命令消息`），
    可精确定位命令未被识别时的真实文本内容；
- 页面资源版本参数升至 `?v=0.29`。

## 说明

- 请重载后重试 /reset：若日志出现「防抖判定非命令」，请把该行文本内容反馈给开发者（即为真实提取到的消息文本）。
- 版本备份：工作区 backup 目录下的 `astrbot_plugin_storyteller_alpha-0.29`。
