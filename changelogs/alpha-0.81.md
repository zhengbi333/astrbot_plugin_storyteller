# alpha-0.81 —— 状态页彻底改版：响应式卡片仪表盘（替代固定三栏）

> 回应「右栏太长了 / 右边出框 / 背景板也出了，效果不好」：alpha-0.80 在固定 330px 窄栏里硬塞两列网格，
> 内容溢出且破边。本次**放弃状态页的固定三栏方案**，改为**响应式卡片仪表盘**：
> 卡片用 `repeat(auto-fit, minmax(250px, 1fr))` 自动换行，任何视口宽度都不会横向溢出。

## 变更

- **布局彻底重做（不再分三栏）**：
  - 顶部一排：状态锚总开关 + 轻量事件演化总开关 + 「演化」（一键生成 + 节拍/来源说明）并排（flex-wrap）；
  - 中部两组**自动适配网格**：A 组（此刻 · 心绪三表 / 心事 / 最近余波 / 互动涟漪）、B 组（语气走廊 / 手动微调 / 演化节拍记录 / 状态怎么随对话变）；
  - 底部「状态设置」区域：状态模型 + 当前天气 + 六个设置项全部铺开在 `auto-fit` 网格里。
- **防溢出**：`.dash-grid` 用 auto-fit + `minmax(250px,1fr)`；面板内文字 `overflow-wrap:anywhere`、
  `min-width:0`；取消网格内 `.panel + .panel` 的竖排 margin（统一由 gap 负责）。
- 数据与功能零改动：配置键、API、绑定（主开关/演化/应用）全部不变。
