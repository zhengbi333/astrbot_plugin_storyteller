# alpha-0.23（2026-08-08）

## 变更

- **LLM 请求拦截下沉为「最下游」**：
  - 拦截器 priority 由 1000 改为 **-100**（低于记忆插件等所有插件），
    保证拦截到的是**最终决定发送给 LLM 的内容**（各插件修改完毕后的完整请求）；
  - 阻断仍发生在 LLM 调用之前（stop_event），不产生 token 消耗。
- **新增「消息防抖」功能**（设置页新增大类 + 顶部导航新增「防抖」选项卡）：
  - 按会话（unified_msg_origin）收集用户短时间内的连续消息：窗口内新消息重置倒计时，消息被静默
    （不触发 LLM）；到期后把合并内容写回锚事件并恢复传播，正常发送给 LLM；
  - 自适应等待：按消息长度与结尾标点动态调整（短句/未完成标点等待更久），并受单轮与总等待上限约束；
  - 命令消息立即结算现有缓冲并放行；撤回通知在窗口内移除对应消息；仅私聊（可配置）；
  - 静默机制与 AstrBot 对齐：`should_call_llm(True)` + `clear_result` + `stop_event`；
    结算时 `continue_event` 恢复锚事件传播；
  - 「防抖」选项卡展示活跃会话（条数/预览/剩余倒计时/立即结算）与结算历史；
  - 接口：`GET /debounce/status`、`GET /debounce/history`、`POST /debounce/flush`。
- 与既有功能协同：防抖窗口内的每条消息仍可被记忆插件正常记录时间线（防抖 priority 60 晚于其捕获入口）。

## 说明

- 防抖默认关闭（`debounce.enabled=false`）；开启后机器人只在合并完成后回复一次。
- 实现独立编写（参考示例插件思路：会话缓冲 + 计时重置 + 合并重构 + 静默/放行；无雷同代码）。
- 专项验证：首条静默收集、窗口内追加、结算合并与恢复传播、撤回过滤、命令立即结算、关闭放行。
- 版本备份：工作区 backup 目录下的 `astrbot_plugin_storyteller_alpha-0.23`。
