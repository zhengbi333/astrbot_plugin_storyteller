# alpha-0.101（内心拟人心智升级）

按用户拍板三项实现：日记记忆+人格联动 / 思考事件驱动+每日可配限次 / 梦境长梦+素材+行为联动。

## 1️⃣ 日记 = 她的人生（记忆+人格联动）

- `_write_diary` 注入：人格注入体（她是谁/世界观）、性格/说话方式、**最近记忆（约定/愿望/重要事，8 条）**、最近亲近的人（关系表）；
- `build_diary_prompt` 明确要求"把『她是谁』与记忆里的约定/重要事自然融进去——是她这个人的一天，不是流水账"；
- 保留原有素材（状态史/梦/思/见闻/对方情绪）。

## 2️⃣ 思考 = 事件驱动 + 每日限次（用户可设，默认 7）

- 新配置 `mind.think_daily_limit`（默认 7，1~24）：每天最多冒几回念头；
- `_mind_loop` 白天分支重写：仅当**最近 6 小时发生过事件**（对话/情绪/画像/日程活动）且
  **30~90 分钟随机窗口**已过、当日次数 < 上限 时才生成一次（`_recent_event_window`/`_recent_event_text`）；
- 提示词携带"由头"（对方最近情绪/最近聊到的/此刻日程），念头顺着由头转；
- 计数/上次时间存 mind_store `_meta`（跨重启有效，按天重置）。

## 3️⃣ 梦境 = 一夜一条长梦 + 白天素材 + 行为联动

- **一夜一条**：深夜（23~06）按日期去重（`last_dream_date`），提示词要求"一整夜连贯长梦（80~200 字）"；
- **白天素材**：`_dream_material()` 收集今天心情起伏/对方情绪/发生的事/见闻/心里记着的，揉进梦；
- **余波**：`_dream_aftermath()` 按关键词归类 nightmare/sweet/ordinary，存 `dream_aftermath`（供状态/主动对话取材，后续主动功能接入）；
- 手动「生成梦境」同样走长梦逻辑；白天手动/后台不重复。

## 4️⃣ 前端：梦境/思考「只展示当前 ⇄ 分页展示」

- 每个区块头部 pill 切换：「只展示当前」（默认）= 最新一条大卡 + **左侧橙色线**（the 此刻高亮）；
  「分页展示」= **5 条/页** + 页码/上下页，翻页局部重渲；
- 见闻自动分页（5 条/页，无切换——始终分页）；删除由绝对索引定位。
