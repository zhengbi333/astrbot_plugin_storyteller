# alpha-0.5（2026-08-08）

## 变更

- **防缓存**：页面引用的 `style.css` / `app.js` 增加版本查询参数（`?v=0.5`）。此前浏览器/iframe 缓存旧版脚本，导致修复项不生效（已从外观配置中残留的旧主题名 `lunar` 确认用户一直加载的是旧前端）。
- **进度条填充重写**：不再依赖 CSS 变量 `--fill`（存在兼容性问题），改为 JS 直接设置滑块背景渐变（读取当前主题色实时计算），拖动与渲染均同步；CSS 默认填充改为 0%。
- **背景效果语义明确**（原「背景板」改名「背景效果」）：
  - 文案说明打开条件：选择背景色、调整透明度/模糊或上传背景图时会**自动开启**，也可手动开关；
  - 颜色选择、滑块调整时自动启用背景效果；
  - 开关文案：「背景效果已开启 / 未启用」。
- **上传流程明确反馈**：选中文件后立即提示「正在上传…」，成功提示「背景图已更新」，失败显示具体错误并重置选择框，不再静默无反应。
- **保存确认**：外观变更持久化成功后提示「已保存」，失败提示「保存失败，已回滚」。
- **后端诊断日志**：外观读取/保存/恢复/上传/清除接口均记录调用日志与关键参数，便于定位问题。

## 说明

- 后端 API 结构不变，已有外观配置兼容（含旧主题名自动回落默认主题）。
- 版本备份：工作区 backup 目录下的 `astrbot_plugin_storyteller_alpha-0.5`。
