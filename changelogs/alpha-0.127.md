## Token 页修复与样式调整（0.126 验收反馈）

- **修复「为你续写的故事」token 统计卡全 0**（你反馈的第 1 点）：
  - 根因：旧版（0.124 及以前）token.json 没有来源维度（顶层 `total` 直接归属陪伴插件自己），
    新版按来源统计时只从 `by_source` 取数 → 旧数据在来源卡显示 0，而任务明细走了
    「无冒号键视为 companion」的兼容路径所以有数据；
  - 修复：`TokenStore._totals` 对旧结构日回退用顶层 total（companion 来源）；
    升级当天记账时把旧顶层 total **迁移**进 `by_source.companion`（旧量不丢、不双计）；
  - 回归：smoke_token_usage 增 4 项（companion 可见旧数据 / main 不受旧数据影响 /
    同日迁移合并 / 全来源合计一致），30 项全绿。
- **统计栏进度条 → token 小卡片**（你建议的第 2 点）：
  - 明细区「总计 / 今天 / 本月」三条进度条改为三张 token 小卡片（大数字 + 入/出 + 调用次数），
    与来源卡风格一致（青绿淡底、tabular 数字）；按任务列表保留进度条作排行对比。
  - verify_057 增 2 项断言（小卡结构/数值），122 项全绿。
