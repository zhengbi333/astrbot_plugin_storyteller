# alpha-0.180

## 表情包界面：导入的图无法预览/编辑（补全图库缩略图与逐张删除）

- **用户反馈**：表情包页导入的表情包无法预览和编辑（是否删掉他？）。
- **根因**：前端图库区只渲染「分类标题/编辑/删除分类 + 上传框」，**从未渲染已上传图片的预览**，也没有单张删除入口——后端 `emoji/remove` 早已存在但前端无 UI；`emoji/categories` 只返回 `count`（无文件列表/可显示 URL）。
- **修复**：
  - 后端：`emoji.py` 新增 `files_with_preview(cid, limit=8)`（每张原图 data URL，>2MB 跳过预览仍可删）；`emoji/categories` 每分类附带 `files`+`preview_total`（8 张上限，超出提示"还有 N 张未显示"）；
  - 前端：图库分类卡片内渲染缩略图（64px 圆角网格，动图原图直接播放），每张右上角「×」→ 确认对话框 → `emoji/remove` 删除后刷新；上传成功即刷新显示新图。
- **验证**：后端单测（临时目录：上传→预览→删除→10 张限 8 预览）通过；`py_compile` 通过。
