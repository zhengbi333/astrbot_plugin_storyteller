## 「在此之前的部分上下文」说话人标注 + 时间正序（用户观察：无标注且倒序，模型会误解）

- **用户指出（正确）**：快照里 `【在此之前的部分上下文】你呢，吃了吗？/正准备吃饭。/阡墨，在干嘛呢`——**没有标注哪句话是谁说的**，而且顺序是**最新在前（倒序）**（"阡墨，在干嘛呢"是用户的话却排在最后）；顺带确认：两条快照是 12:58 与 13:02 的**两次独立接管调用**（面板显示最近两条）。
- **根因**：`_recent_timeline_text` 从记忆插件时间线取最近 N 条后**只拼接正文**（丢弃 role/发言者/时间），而时间线源返回**最新在前**——模型面对无标注、倒序的对话行，无法分辨"你呢，吃了吗？"是谁问的。
- **修复**：
  1. **每行标注说话人**：user → 昵称（无昵称用"对方"）；bot → "我"；其它 → "系统"；
  2. **按时间正序渲染**（首行时间晚于末行时反转），旧→新自然阅读；
  3. 文本截断（100 字）与 `is_llm_context_event` 过滤不变；`_dedupe_current_message` 仍生效（当前消息行带标注后同样被剔除——按内容匹配）。
- **效果（13:02 场景变成）**：
  ```
  【在此之前的部分上下文】
  对方：阡墨，在干嘛呢
  我：正准备吃饭。你呢，吃了吗？
  ```
