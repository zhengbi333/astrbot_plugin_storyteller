# alpha-0.75 —— 接管改换（直连）尽力回写会话历史

> 按确认方案：接受现状分工（接管走主链=主链默认模型进历史；接管改换=直连指定模型+自处理管线），
> 并为「接管改换（直连）」补充**尽力写回事件/set_result**，尝试让直连回复被计入 AstrBot 会话历史。

## 变更

- 「接管改换（直连）」生成并发送回复后，调用 `_try_set_event_result` 尽力 `event.set_result(...)`
  （兼容不同版本：优先 `MessageEventResult(content)`，失败则传字符串；失败静默）。
  是否真计入历史以实机为准——若您的 AstrBot 版本支持 set_result 计入会话历史，
  则直连回复也能续上多轮上下文；否则靠防抖/记忆插件时间线保持上下文（现状）。
- 「接管走主链」维持现状（主链默认模型 + 完整进历史/管线），不改动。
