# alpha-0.185

## 修复「生图上下文链路自引用」：当前消息已先写入时间线，导致 A1/软标记/主题锚定全部失效

- **症状（实测日志）**：「晚霞好美 → 好看吗？」时**生图意愿软标记未打出**（无"生图意愿软标记"日志），bot 正常聊天未提议；同样影响 0.182 的「云→给我看看/拍个照发我」主题锚定（可能仍画人像）。
- **根因（证据链）**：deepmemory 的 `capture` 钩子（priority **1500**）先于 storyteller 的 `on_llm_request`（priority **10000**）执行——**当前用户消息在生图判定前就已写入时间线**；`_image_recent_user_text` 取"最近 user"= **当前消息自己**（"好看吗？"），无画面主题词 → A1 门控/软标记/泛词锚定全部返回空 → 静默失效。
- **0.185 修复**：
  - `_image_recent_user_text` 增加 `exclude_text`（当前消息）过滤：同内容/互为包含即跳过，继续向前找真正上一条用户发言；A0 泛词锚定、A1、软信号三处调用全部传入；
  - 软信号检测新增 INFO 诊断日志（weak_hit 后打印 session/prev/subj），下次可直接从日志看到每步决策，杜绝"静默失败"再排查；
- **验证**：模拟时间线（好看吗？→bot→晚霞好美）排除当前消息后命中"晚霞好美"、主题词="晚霞" ✓；`py_compile` 通过。
