# alpha-0.39（2026-08-16）

## 修复

- **导航栏**：去掉边缘渐隐遮罩（之前「总览」「调试」选项卡滚动到边缘时被淡化）。
- **状态页 Internal server error**：兼容旧版 presence.json（energy 为文字的历史数据），
  数值字段安全转换后不再报错。
- **表情包上传失败（Missing uploaded file payload）**：改为 `bridge.upload("emoji/upload?cid=xxx", file)`
  传 File 对象，分类 id 走 query 参数。

## 变更

- **日程重做（LLM 动态生成）**：
  - 生成时结合人格（风格）+ 记忆（约定/愿望/偏好）+ 天气 + 当前状态 + 衣柜 + 未来规划 + 延误池，
    让 LLM 生成"她真实的一天"（活动具体、贴近生活）；
  - 新增两个缓存池：**未来规划**（未排进某天的事，下次生成综合判断是否排入）、**延误日程**
    （被替换的原计划，标注原因，有空补上）；
  - 日程页三面板：当天日程（当前时段左侧青线 +「▶ 此刻」高亮）+ 未来规划 + 延误日程；
    一键生成新日程带「覆盖当前日程」确认警告。
- **穿搭与衣柜**：新增「穿搭」选项卡——当前穿搭（穿戴 + 理由，可编辑）+ 衣柜（上限 30 件，可增删）；
  穿搭由 LLM 从衣柜里选，结合天气/场合/心情给理由；生成日程时一并确定衣柜与当日穿搭。
- **LLM 工具**：新增 `get_schedule`（检索日程）、`set_schedule`（改写日程，原计划自动入延误池并标注）、
  `add_future_plan`（记入未来规划）、`get_outfit`（读取穿搭/衣柜）、`set_outfit`（修改穿搭）。
- **设置页**：隐藏「模型」模块（模型配置只在「模型」标签页展示，不再重复）。
- 页面资源版本参数升至 `?v=0.39`。
