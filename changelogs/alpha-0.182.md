# alpha-0.182

## 生图「主题锚定」+ 人设注入弱化 + caption 可配（QQ 实测截图实证：画成了人设人像图，与话题无关）

- **用户反馈（正确，附截图）**：聊「云」话题下请求「拍个照发我/给我看看」→ 生成图是**实验室人设人像**（灰色卫衣/黑裤/白帆布鞋/眼镜 = 衣柜穿搭+人格注入强引导），与画面主题无关；并附带写死的「给你画好啦～」。
- **0.182 修复**：
  - **泛词锚定**：规则命中但描述是泛词（照片/图/一张/自拍/拍）时，取同会话最近用户发言的**画面主题词**（云/天空/天气/晚霞/夕阳/星空/雪/花/海/山/风景/猫…），描述改为「云的景象（对方在聊这个）」——聊云拍「照」= 画云，不再画人像；
  - **A1 门控收紧**：索图式短问（词表扩展：啥样/什么样/咋样/好看吗/好看不/漂亮吗/美不美…）**必须**上文含画面主题词才命中（「你皮肤怎么样→好看吗」不再误吸）；描述同样用主题词；
  - **人设注入弱化**：画面内容置顶；角色设定改为「仅在画面必须出现人物时参考；不要为了展示人物改变画面主题」（500 字）；**当前穿搭/人物气质仅在画面明确要人物（自拍/人像/我/你）时才注入**——主题画面（风景/云/猫）不再被穿搭带偏；
  - **caption 可配**：`image.caption`（新配置项，默认「给你画好啦～」，留空=纯图不附文字），生图页「后端与限制」卡内新增字段。
- **验证**：主题抽取（云/天气/晚霞 ✓，闲聊「皮肤/实验室」不命中 ✓）；索图判定扩展（给我看看/好看吗 ✓、「今天的日程看看」False ✓）；`py_compile`/schema 通过。
