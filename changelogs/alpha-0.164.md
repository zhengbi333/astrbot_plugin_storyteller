# alpha-0.164

## 修复：提示词"乱"——0.162 的【本次对话】补丁与模板裸文本并存（重复一遍带标签一遍不带）+ 记忆元信息句触发"走神"

- **用户指出（完全正确）**：快照里 `你好 / 证毕（<用户ID>）/ 私聊`（模板里裸文本、无标签）之后又跟一段 `【本次对话】对方刚刚说：你好…`（带标签）——**同一信息两遍，一遍没标签一遍有标签，很乱**。
- **治本方案（替代 0.162 补丁）**：`_labelize_anchors(template, anchors)`——**替换前直接给占位符内容加语义标签**：`{当前说话}`→"对方刚刚说：你好"、`{当前用户}`→"当前和你对话的人：证毕（<用户ID>）"、`{场合}`→"发送场合：私聊"；**仅当模板中该占位符相邻 14 字内没有标签词（说/话/讲、对话/人/用户、场合/境）时才加**（模板已自带标签如【对方说】则不重复加）；**删除 0.162 的【本次对话】追加段**——一处显示、处处有标签。
- **"走神了再说一遍"真正触发点**：快照里 `{记忆}` 注入包那行"证毕在2026-08-28 17:57给我发了消息。这条消息旨在说明你知道对方叫证毕，与亲密度、互动等无关。"——**元信息记忆**让模型以为"对方发过一条我没看到的消息"。新增 `_clean_memory_meta`：剔除含"旨在/这条消息旨在/与亲密度/与互动等无关/希望你了解"标志的行。
- **配套**：索要检测新增"装没听见"整类（"再说一遍/再说一次/没听清/没听到/没注意/走神了/刚才说了什么/刚刚说了什么"→ 直接命中 → 重生成 → 仍装 → 固定短句）；0.161 去框架注措辞改"注意：上方就是你本人，直接以本人平常的口吻回应对方刚才说的那句。"（删掉"对方这句话就是全部"——断言句会诱导模型过度解读）。
