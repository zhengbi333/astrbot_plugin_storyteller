# alpha-0.83 —— 顶部导航回滚 + 状态页重排：设置在右栏、消空白

> 回应两条意见：① 顶部选项条改回原样（换行布局破坏拖拽选项卡索引判定）；
> ② 状态页 UI 重排——设置页不再压在底部，放在**右侧固定栏**（窄屏置顶），并消除卡片空白。

## 变更

1. **顶部导航回滚**：`.topbar-inner`/`.topnav`/`.nav-item`/720px 窄屏规则全部恢复为
   **横向滚动式**（`overflow-x:auto`，滚动条细）——拖拽选项卡索引/判定保持原实现，无回归。
2. **状态页改为「顶部主开关行 + 两栏主体」**：
   - 顶部一行：状态锚总开关 + 轻量事件演化总开关 + 「演化」（一键生成/节拍/来源）；
   - **左栏（弹性）**：内容卡网格——此刻·心绪三表 / 心事 / 最近余波 / 互动涟漪 / 语气走廊 /
     手动微调 / 演化节拍记录 + 全宽「状态怎么随对话/事件变」；
   - **右栏（330px 固定）**：「状态设置」——状态模型 + 当前天气 + 六设置项单列紧凑排布，
     说明条收窄；**点开状态页即看到设置**；
   - 窄屏（≤980px）右栏置顶（`order:-1`），保证移动/窄视口下设置也最先可见。
3. **消除空白**：设置卡 `padding` 收紧、hint 行高 1.55；内容卡 panel-head 下边距 10px、hint 1.65；
   右栏 sticky 跟随滚动。
