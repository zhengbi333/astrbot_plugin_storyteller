# alpha-0.10（2026-08-08）

## 变更

- **保存不再被界面渲染异常阻断**（关键修复）：
  - 根据诊断日志确认：点击主题后 `applyAppearance` 完成、随后 `render()` 抛出异常，导致保存请求从未发出；
  - 现在 render 异常被隔离捕获：**即使界面渲染失败，保存请求照常发出**，成功提示「已保存」，失败提示「保存失败，已回滚」；
  - render 异常的具体错误（消息 + 堆栈首行）写入诊断面板，可精确定位。
- **新增「插件调试」选项卡**（按建议）：
  - 后端新增 `GET /logs` 接口，返回 `storyteller.log` 尾部 200 行；
  - 页面「调试」页以等宽字体展示运行时日志，可一键刷新。
- 页面资源版本参数升至 `?v=0.10`。

## 说明

- 测试步骤：重载插件 → 强刷 → 点击主题 → 观察诊断面板（左下角）与右上角提示：
  - 应出现「已保存」；刷新后主题保持；
  - 若诊断面板出现 `render 异常（已继续保存）: xxx`，请把该行内容反馈给开发者，即可定位渲染崩溃点。
- 版本备份：工作区 backup 目录下的 `astrbot_plugin_storyteller_alpha-0.10`。
