# alpha-0.102（设置页模块化瘦身 + 日记本）

## 1️⃣ 设置页瘦身：只留「模型配置」，其余全部模块化（用户拍板方案）

设置页子选项卡从 5 个 → **只剩 models**（全局生成策略：流式/超时/思考开关/回退模型——这是唯一"属全局、无归属页"的主干）。

迁移去向：
| 原设置大类 | 迁向 |
|---|---|
| general（页面动画/类型/时长） | **「外观」页**新增「页面动画设置」展示板 |
| general（日志面板刷新间隔） | 外观页同卡（含 log_poll_interval） |
| memory（记忆联动：托管注入/约定/画像/嵌入/画像/约定模型） | **「拦＆改」页**新增「记忆联动」设置区 |
| pipeline（链路：总开关/关系判断开关/判断模型——模型此前已在关系页） | **「关系」页**右栏补齐 enabled / judge_enabled |
| vision（识图开关/模型） | **「防抖」页**右栏新增「图片识图」设置卡 |
| search（引擎/Key/结果数/自主浏览/间隔/模型） | **「内心」页**右栏「搜索设置」（引擎/Key/结果数此前在设置页） |
| mind | **「内心」页**右栏（此前已迁） |

- 所有迁移项沿用统一 `.setting-card` 展示板 + 自动保存（renderSettingField / bindSettingsIn）；
- 各页缺失配置时渲染独立 fallback 项（不依赖设置页先加载），页面可独立直达。

## 2️⃣ 内心页：分页 3 条 + 日记本

- 梦境/思考「分页展示」改为 **3 条/页**；「只展示当前」保留（左橙线高亮最新一条）；
- **日记本**：从左侧挪到中栏「梦境/思考」下方，**时间轴样式**——左侧渐变竖线 + 圆点、日期徽章（chip）、
  纸感卡片、今日条目高亮描边（.diary-book / .diary-book-entry / .diary-date-chip / .diary-text）；
- 左栏改放「见闻 + 手动搜索」（与搜索设置同页配套），右栏「内心设置 + 搜索设置」。
