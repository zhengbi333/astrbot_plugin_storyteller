# alpha-0.212

## 第 9 轮迭代：主动消息质量体检 → 修掉"新闻播报"与偏长

### 诊断（真实配置 + 真实数据 + 真实模型）

你配了主动对话（09:00–22:00 / 4~8 小时间隔 / 每日 3 条 / 未回应降速），但状态文件里
`last_sent_at: 0.0`——**从来没发出过**。这一轮把它整条链路走通并量了一遍：

| 检查项 | 结果 |
|---|---|
| 闸门（`_should_send`） | **正常**（静默 / 每日上限 / 免打扰 / 刚聊完顺延 / 未回应降速阶梯都在） |
| 由头素材（`engine.collect`） | **不缺**：真实数据里有 4 条（状态 / 见闻 / 梦 / 三餐） |
| 生成质量（4 个手写场景） | 好：「记得抽完血吃点东西。」「今天晚霞很好看，想你也能看到。」 |
| 生成质量（**4 条真实由头**） | **发现两个问题** ↓ |

**问题一：见闻类由头被原样"播报"**
由头是 93 字的新闻摘要，模型生成：
> 「刚刷到特朗普让AI巨头签自愿安全协议叫它"超级智能"，转头又看到OpenAI早收到警告没当回事，有点睡不着。你那边有听说什么吗？」

——像新闻联播，不像人随口提一句。

**问题二：整体偏长**
四条真实由头的生成平均 **38 字**（最长 55 字），而人设是"话少"、主动消息更该像随手发一条。

### 修复

在主动消息的内置提示里补两条约束（只影响内置默认；你自己配了 `proactive.template` 的话不受影响）：
- 「像随手发出去的一条消息：**一两句、十几二十字就够**，别写成一段话；」
- 「由头只是「你为什么想起对方」，**别把由头的内容原样复述出来**（比如看到新闻，说「刚看到条新闻有点闹心」就够了，不用把标题念一遍）。」

### 效果（同一批真实由头，真实模型）

| 由头 | 改前 | 改后 |
|---|---|---|
| 见闻（93 字新闻） | 「刚刷到特朗普让AI巨头签自愿安全协议叫它"超级智能"，转头又看到OpenAI早收到警告没当回事…」（**55 字，播报标题**） | 「**刚刷到几条AI安全的新闻，越看越清醒了，你睡了吗？**」（25 字） |
| 状态（困） | 「今天在实验室待了太久，脑子已经转不动了，你那边怎么样？」（30 字） | 「**实验做不动了，跟你念叨两句提提神。**」（17 字） |
| 梦（120 字） | 「我这边离心机刚停，灯白得人发愣，梦里跑出一条歪曲线…」（50 字） | 「刚看到几个新闻，心里堵得慌，有点想你了。」（20 字） |
| 三餐 | 「晚饭吃了吗？我在实验室有点困，想到你了。」（17 字） | 「晚饭吃了吗，我这边实验刚告一段落，困得不行了。」（23 字） |

**平均 38 字 → 21 字；播报式复述消失。**

## 关于"你从没收到主动消息"的结论（重要）

**不是 bug**：闸门正常、素材有、生成质量好。原因是**运行时长不足**——它需要同时满足
"在 09:00–22:00 内、距上次说话 ≥30 分钟、距上次主动 ≥4~8 小时、当日 <3 条"。
你之前只在 9-06/9-07 用了两天、断断续续，所以还没轮到它开口。
**把 AstrBot 挂着、正常聊几次之后，它会自己找你说第一句话**（而且现在说的是更像人话的样子）。
