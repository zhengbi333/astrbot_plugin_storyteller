# alpha-0.86 —— 状态页空隙回填 + 占位符描述修正（穿搭不占位）

> 回应两条意见：①「心事」下方、「互动涟漪」上方有大块空白，建议把「状态怎么随对话/事件变」放进去；
> ② {日程} 占位符写的是「今日日程与穿搭」，但穿搭模块并没有占位符——描述与实际不一致。

## 变更

1. **状态页空白回填**：「状态怎么随对话/事件变」从网格外（网格下方的独立全宽卡）**移回网格内**、
   紧跟「心事」之后（第 3 位）——2 列排布时它正好落在「此刻」高卡右侧的空隙里，
   长文本填平空洞，后续卡片（最近余波/互动涟漪…）继续流式排布，无空列。
2. **占位符描述修正**：
   - `{日程}` 描述改为「今日日程（只注入日程，不含穿搭）」——与实际注入（build_schedule_anchor 只渲染日程）
     一致；
   - **穿搭页新增占位符说明卡**：「（无占位符）穿搭不走模板占位符：对话中 Bot 通过 LLM 工具
     （get_outfit/set_outfit）读取或修改当前穿搭，需要时对方问起即可；不要在模板里找 {穿搭}。」
     ——把「为什么穿搭没有占位符」讲清楚，消除误解。
