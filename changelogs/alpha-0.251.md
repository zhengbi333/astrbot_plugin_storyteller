# alpha-0.251

之前她说错了只会硬顶；现在能收回来。

## 怎么判「该撤」

只认**对方明确指出你说错了**，不猜"自己觉得不好"（那种判断容易把正常发言撤掉，比不撤更糟）：

| 触发 | 例子 |
|---|---|
| 明确纠正 | 「不是这个意思」「你理解错了」「你误会了」 |
| 指定内容 | 「我说的是…」「答非所问」「重新回答」 |
| 直接要求 | 「撤回」 |

**反例（不撤）**：「不用撤回」「别撤回」「算了」—— 出现这些词一律不撤。

## 流程

1. 每次发出回复时记下 `message_id`（接管链路已接）；
2. 对方下一句命中触发词 → 取出那条记录；
3. 检查是否在 OneBot 的 **115 秒**时限内（官方 120 秒，留 5 秒余量）；
4. 在时限内就 `delete_msg` 撤回，然后重新回答；超时则丢弃记录，不撤。

## 安全边界

- **默认关**（`recall.enabled`），要开才开；
- 每个会话只留**最近一条**可撤记录，不会误撤更早的；
- 撤回失败一律静默（拿不到 bot / 平台拒绝 / 超时都不影响正常回复）；
- 只撤**自己**发的消息，从不碰对方的消息。

## 已知边界

- 只在**接管链路**记了 `message_id`；主链（AstrBot 自己发消息）暂时拿不到 id，那条路径不会撤；
- 不支持撤回后自动改写（只是撤掉 + 重新回答）；
- 触发词是字面匹配，讽刺式纠正（「你可真会理解」）认不出来。
