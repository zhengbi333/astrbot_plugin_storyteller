# alpha-0.121

## 组合消息连续性

- **会意并行化**：识图/文件摘要/链接要点由串行（各 15-20s → 合计 60s+，可能撞接管 90s 上限）改为 asyncio.gather **并行**，总时长 ≈ 最慢一个（~20s）。
- **防抖保件**：窗口内分条发送时，File/Share/Video/Record/无 url 表情组件此前在合并时被丢弃——现在收集并原样拼回重构的消息链，AstrBot 主链与插件都能再见到它们。
- 新设置：`vision.media_retry`（0-3，默认 0）——单个媒体子调用失败/超时后的重试次数（每次完整超时窗口）。

## 文档完整性（不再只读开头）

- `vision.file_max_chars` 默认 20000 → **40000**（可配 2000-200000）；
- 超限自动**分块全读**：按 1.2 万字符分段逐段理解，最后整体汇总——长文档任务（总结/分析/续写）不会被截断；
- **新增格式**：Word(.docx)/PPT(.pptx)/Excel(.xlsx/.xlsm) 通过 zip 标准库提取文本（零新增依赖）；PDF 用 pypdf（环境已有，缺失则仅记文件名）。

## 表情包 vs 图片 vs 动图

- **Face id→名称映射表**（QQ 常用表情 80+，含新版狗头/笑哭/裂开等）：观察层与基础标记显示「[表情：狗头]」；
- 表情包图/梗图 vs 真实照片/截图：识图模型**语义裁决**（输出 [表情]/[图片] 类型标记），提示词加权「拿不准归表情」；规则信号（GIF/文件名）会在动图路径使用；
- **动图多帧连贯**：`vision.gif_frames`（默认 3）PIL 均匀抽首/中/尾帧，同一次识图多帧传入，理解动图整体表达。

## 回复克制（不再复读机式夸图）

- 识图结果分层注入：表情包 → 「（对方发了个表情包：…。别当成必须回应的内容；顺带提一句或不提都自然）」；照片/截图/作品 → 「（对方发来的图片：…。值得接话时可以自然提起；不必对每一张图都点评）」；
- 接管直连的媒体会意同样带此引导。
