# alpha-0.197

## 能力工具化 · 阶段 1（上）：能力注册表 + 接管文本协议 + 首四个能力

用户裁断：路线 **D + C 全做**、能力**全覆盖**、协议用 **`[DO:能力]{json}`**、由我自主验证迭代。本版是阶段 1 的第一部分。

### 新增 `capabilities.py`：能力注册表（单一真源）

- 每个能力只声明一次（名称/说明/参数/示例/适用链路/是否需设定写权限/每日限额/实现），**主链工具注册**与**接管模式声明段**都从这里生成，避免两处各写一份、行为分叉。
- 结果统一结构 `{ok, status, message, next_hint}`：`next_hint` 直接引导模型下一句怎么说（借鉴"失败可见、不谎称已做"的经验：只有真成功才允许说"我记住了"）。
- **去重登记**：本轮已通过能力完成的动作写到事件上（`caps_done`），供各预检测判断"这个动作已经有人做了"。

### 接管改换：能力声明 + 文本协议执行（真正让模型"主动做事"）

- **声明段注入**：组装 system 时追加「你可以主动做的事」清单（含格式与示例）——接管直连不带 tools，这是模型获得主动权的通道。
- **标记执行**：生成后解析 `[DO:能力]{json}`（容错：JSON 坏了按空参数）→ 执行（一次最多两个）→ **结果回灌 system 再生成一轮**（`capabilities.max_rounds`，默认 1，与 0.194 的"打断合并"共用同一循环）。
- **不泄露**：标记在发送前一定被剔除（执行后 + 最终保险两道）。
- **与既有链路协调**：① 本轮执行过能力 → **跳过沉默判定**（模型明显想回应）；② 已用 `emoji_send` → **跳过表情包判定**（避免双发）；③ 打断合并与能力轮次在同一循环里统一调度。

### 首批四个能力

| 能力 | 作用 | 关键行为 |
|---|---|---|
| `memory_write` | 写入长期记忆（fact/preference/promise/todo） | 桥未联动/写入失败 → 返回 `next_hint`：**如实说没记住，别谎称已保存** |
| `memory_recall` | 检索长期记忆 | 无结果 → 提示"如实说记不太清，别编造" |
| `web_lookup` | 联网搜索要点 | 结果同时写入 `{搜索结果}` 缓存；无结果 → 如实说没查到 |
| `emoji_send` | 挑一张表情包随回复发出 | 尊重 opt-out；图库空 → 只用文字（别说要发） |

### 配置（`capabilities` 模块）

`enabled`（总开关，默认开）、`max_rounds`（能力执行轮次上限，默认 1，最多 4）、`memory_write_daily` / `memory_recall_daily` / `web_lookup_daily`（默认 20）/ `emoji_send_daily`（0=不限）。
