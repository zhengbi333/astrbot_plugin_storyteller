# alpha-0.67 —— 关系模块：人物卡 + 印象提炼 + 联动 + 三栏页面 + 手动调整

> 按已确认方案落地关系模块（"更像人"）：人物卡多维、印象提炼三层机制、联动读记忆插件、
> 三栏页面、judge 模型搬入关系页、手动调整好感/称呼。

## 新增 / 变更

- **人物卡字段**：基础（称呼/好感/阶段/档位/互计数/时间戳）+ **最近印象 impression**（LLM 提炼）+ **约定/偏好**（联动只读，不重复存储）+ 互动留痕（内存缓冲供提炼）。
- **三层更新**：
  1) 即时轻量层（每次消息，不调 LLM）：好感 ± / 称呼 / 互计数；
  2) **印象提炼层**：攒满 `relationship.impression_batch`（默认 10，可改）条互动、且距上次提炼 ≥ `relationship.impression_min_interval`（默认 30 分钟，可改）→ 异步调**关系判断模型**，输出 `{delta, impression, reason}` → 微调好感 + 写入最近印象（输出解析带防御）；
  3) **联动层**：注入 `{关系}` 时读取【为你篆刻的历史】该会话的 promise/preference/relationship 摘要（`list_recent_memories(memory_type=...)`，最多 6 条、每条≤60 字，只读不写）。
- **{关系} 注入升级**：阶段＋档位＋称呼＋最近印象＋约定/偏好摘要，末尾"只用于把握分寸，身份以账号/ID 为准（见防认错）"。
- **关系页三栏**：左＝关系档案列表（点击选中）；中＝人物卡（称呼/好感 0–100 手动改＋保存、阶段/档位、最近印象、{关系} 注入预览）；右＝关系设置（总开关＋印象触发条数/最短间隔配置＋**关系判断模型下拉**）。
- **judge 模型搬移**：关系判断模型（`pipeline.provider_id`）在关系页配置；**设置页「链路」不再显示「判定模型」**（其余回复链路总开关/二次润色/智能判定仍留在链路）。
- 手动调整：`RelationshipStore.update_manual`（好感→自动重算阶段、称呼）；新 API `POST /relationships/update`。
