# alpha-0.109（主动设置易用化）

按用户反馈：删 JSON 时段配额，改为直观设置。

## 修改

- **删除**「时段配额(JSON)」（技术门槛高）；
- **新增「免打扰时段」**（`proactive.quiet_hours`，默认 `23:00-08:30`）：跨零点 `HH:MM-HH:MM` 写法，这段时间不主动发消息；留空 = 全天可发——与示例插件同风格的克制表达；
- **「每日上限(条)」** 语义升级：0 = 不限制（想多主动就调大）；
- **「想让她主动找的人」**（target_users）：说明改写为**大白话**——QQ 号一人一行最省事；也支持完整会话地址；配套「消息平台(默认 QQ)」；
- 后端 `_should_send`：免打扰时段判断（`_in_quiet_hours` 支持跨零点）+ 每日上限 0 不限；删除时段配额逻辑；
- 附带：验证脚本断言更新（时段配额 → 免打扰时段）。
