# alpha-0.163

## 修复：时间线上下文包含当前轮消息——「你好？」在提示词里重复三次

- **现象**：17:47 实测 /reset 后「你好？」→ Bot 回"嗯，明白。"（正常问候却回"明白"，用户质疑"他在回复什么？"）。
- **证据（用户从「最近发送给对话 LLM 的内容」页面复制的完整快照）**：系统提示里「你好？」出现**三次**——
  ①模板 `{当前说话}` 位置："你好？"
  ②模板 `{上下文}` 位置："你好？"（**元凶**）
  ③`【本次对话】更早的对话：你好？`（同源）
- **根因**：防抖收集时「你好？」已经写入记忆插件（deepmemory）时间线；`_recent_timeline_text` 又把最近 4 条取回来当 `{上下文}`——**当前消息在「对方刚刚说」和「更早的对话」里重复出现**。模型看到"你好？"被说了三遍，以为对方在**重复发问/确认什么**，于是回答"好的，我明白啦！"（→ 润色"嗯，明白。"）——它不是没看懂问候，是对"重复问候"不知所措。
- **修复**：接管两条路径取时间线后调用 `_dedupe_current_message(context, 当前消息)`——剔除与当前消息相等或"当前消息+小尾缀（如媒体标记）"的行；当前消息只由 `{当前说话}` 与 `【本次对话】对方刚刚说` 承载一次。`{上下文}` 为空时留白（无占位句，0.159 语义）。
- **顺带**：这也解释了之前多轮"模型怪脾气"的部分表现——上下文里混入当前消息会让模型把问候当"已聊过的内容"。

## 验证
- 41 项冒烟全绿（smoke_story_takeover 123 项，+3：上下文不含本轮消息、更早记录保留、当前消息只出现两次——对方说+【本次对话】）
- 交互级/layout/deepmemory 回归全绿（见部署输出）
