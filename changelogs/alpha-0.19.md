# alpha-0.19（2026-08-08）

## 变更

- **修复切换选项卡时先播放旧页动画**：
  - 根因：`render()` 未等待异步页面（设置/调试）的数据加载，先给仍显示旧内容的视图容器加上了动画类，
    导致旧页面播放渐入动画后才切换到目标页；
  - 修复：`render()` 改为异步并等待页面内容渲染完成后再触发动画；
  - 同时增加渲染竞态防护：异步加载期间若已切换到其他页面，放弃过期渲染结果，避免内容错乱。
- 页面资源版本参数升至 `?v=0.19`。

## 说明

- 版本备份：工作区 backup 目录下的 `astrbot_plugin_storyteller_alpha-0.19`。
