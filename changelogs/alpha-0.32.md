# alpha-0.32（2026-08-08）

## 变更

- **修复防抖合并后仍无回复（架构性修复）**：
  - 根因：此前防抖对每条消息立即静默返回、由后台计时器结算——结算发生时**消息管道早已走完**
    （事件已按空结果发送并停止），恢复锚事件标志也无法让主链重新执行，因此合并内容永远不会发送给 LLM；
  - 修复：改为**首条消息阻塞式**——首条消息进入防抖时创建会话并**在处理器内等待结算事件**
    （消息管道挂起）；窗口内后续消息追加缓冲并静默；计时器/命令/手动触发仅唤醒等待中的处理器，
    由其完成合并、恢复锚事件（继续传播 + 恢复 LLM 请求标志）并**放行**——消息管道继续，
    主链正常处理合并内容并回复；
  - 命令消息：丢弃缓冲、唤醒等待中的处理器（空缓冲结算为静默），命令本身放行。
- 页面资源版本参数升至 `?v=0.32`。

## 说明

- 专项验证：首条阻塞等待、窗口内追加静默、结算合并+恢复+放行（完整链路）、命令丢弃缓冲并放行。
- 版本备份：工作区 backup 目录下的 `astrbot_plugin_storyteller_alpha-0.32`。
