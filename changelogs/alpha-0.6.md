# alpha-0.6（2026-08-08）

## 变更

- **上传链路全面对齐「为你篆刻的历史」的成熟实现**：
  - 后端：`_request_files()` / `_save_upload()` 兼容层（新 API 与旧版 Quart 均支持），上传先落盘再校验入库，出错返回明确原因；
  - 前端：上传按钮恢复为「按钮 + 程序化打开文件框」模式（与 deepmemory 同款），选中后提示「正在上传…」，成功/失败均有明确提示与错误详情。
- **新增独立文件日志**：插件运行时日志写入数据目录 `storyteller.log`（滚动保留 3 份 × 2MiB），
  所有接口调用（读取/保存/恢复/上传/清除）均记录，不再依赖 AstrBot 控制台，可随时排查。
- **后端兼容层**：`astrbot.api.web` 缺失时自动回退 quart，保证任意 AstrBot 版本可加载（与 deepmemory 同策略）。
- **API 失败可见化**：插件接口不可用时页面顶部显示红色警示条（含错误详情），不再静默。
- **顶部横条防抖**：页面常驻滚动条，切换选项卡时视口宽度不再变化，顶部灵动岛不再伸缩抖动。
- **品牌头像**：顶部横条左侧「续」字替换为插件 logo（`pages/storyteller-panel/logo.png`）。
- **自动保存确认**：外观任一更改即时自动保存，成功提示「已保存」，失败提示「保存失败，已回滚」（原有逻辑保留）。
- 页面资源版本参数升至 `?v=0.6`。

## 说明

- 后端 API 结构不变，已有外观配置兼容。
- 若仍有异常，请查看数据目录 `storyteller.log` 或页面顶部警示条的错误详情反馈给开发者。
- 版本备份：工作区 backup 目录下的 `astrbot_plugin_storyteller_alpha-0.6`。
