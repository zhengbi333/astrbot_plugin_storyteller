# alpha-0.201

## 能力工具化 · 阶段 4 收尾：面板「能力清单」（观测闭环）

四阶段的最后一块：让"模型能主动做什么、做过什么"变成**看得见**的。

### 后端

- `capabilities.dispatch()` 每次执行都记一条**调用日志**（环形 40 条）：时间 / 能力名 / 状态 / 是否成功 / 耗时 ms / 备注（失败原因、限额提示等）；成功、失败、被限额、未知能力都会记。
- 新增 `capabilities.capability_view()`：输出 11 项能力的**标题 / 说明 / 适用链路 / 是否实现 / 限额键 / 每日限额 / 今日用量 / 参数名 / 示例**，加上链路开关状态（`native_tools` / `suppress_regex` / `max_rounds` / `tools_active` / `unsupported`）与**最近 20 条调用记录**（新→旧）。
- 新接口 `GET /capabilities/status`（拦＆改页使用）。

### 前端（拦＆改页新增「能力清单」卡片）

- 顶端一行摘要：`原生工具已启用 / 提供方不支持工具 → 已回退文本协议 / 原生工具未启用 · 轮次 N · 正则已收敛 / 正则兜底生效`。
- 能力逐项列出：标题、能力名、**今日用量/限额**（0=不限）、说明；未实现的能力会标注。
- 「最近调用」区：时间、✓/✗ 能力名、状态与耗时、备注（失败原因一眼可见）。
- 有「刷新」按钮；进入页面自动加载。
