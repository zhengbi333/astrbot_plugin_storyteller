# alpha-0.111（主动页信息密度 + 全面板分页）

## 修改

- **设置保存即时生效**：`saveConfigValue` 成功后自动重渲染当前模块页（主动/内心/日程/穿搭/状态/风格/人格/关系/防抖/拦＆改/润色）——改完设置无需手动刷新/切页。
- **节奏可视化背景板**：顶部"今日已发 N/上限（0 不限）"与"免打扰中/可发时段"改为独立卡片（背景+边框+颜色，醒目）。
- **候选记录卡片化 + 状态色块**：每条一条独立卡片，顶部**彩色状态标注**（已发送=绿 / 发送失败=红 / 沉默=灰 / 被拦截=橙 / 生成中=蓝），原因/素材/文本分开展示。
- **报错汇报台**（候选判定记录下方）：**只记录未发送成的**（失败/拦截/沉默/超时），每条红边卡片 + 时间 + 原因；成功的不进。
- **全部展示面板分页（5 条/页）**：候选判定记录 / 报错汇报台 / 已发送消息——每页 5 条，「‹ 上一页 / 下一页 ›」按钮明显。
- **「立即尝试一次」强化**：金色 glow + ▶ 前缀加粗；触发后**自动轮询刷新**直到出结果（不再要手动刷新才看到沉默/已发送）。
- **「立即尝试一次」竞态说明**：先生成中→1 秒后模型裁决 :NO: → 沉默——正常流程（模型判定快），非 bug。
