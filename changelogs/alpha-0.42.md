# alpha-0.42（2026-08-16）

## 变更

- **防抖选项卡重做**：
  - 左右分栏：左侧为「正在收集的内容」与「结算历史」两个**独立展示面板**（与背景明显区分），
    右侧为防抖设置项；
  - 「活跃会话」改名「**正在收集的内容**」，刷新按钮位于面板标题旁；
  - 「结算历史」支持**分页**（每页 8 条，上限 30 条不变），条目按会话区分用户显示；
  - 右侧设置项**两列卡片**（浅色轻区分，非大黑框），涵盖防抖全部配置（开关/窗口/自适应/
    仅私聊/合并分隔符/撤回过滤/命令前缀等）。
- **设置页**：移除「消息防抖」模块（配置移入防抖选项卡）。
- 页面资源版本参数升至 `?v=0.42`。

## 说明

- 纯前端布局与归位调整，无功能逻辑改动；雷同扫描 0 处。
- 版本备份：工作区 backup 目录下的 `astrbot_plugin_storyteller_alpha-0.42`。
