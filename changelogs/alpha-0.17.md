# alpha-0.17（2026-08-08）

## 变更

- **设置页改为自动保存**：
  - 所有设置项修改即自动保存（开关点击、选项选择、数值/文本失焦即存），保存成功弹出「已保存」；
  - 失败自动回滚显示并提示错误；
  - 移除手动「保存」按钮，保留「恢复默认」（重置后自动刷新）。
- **动画设置扩展**（与「为你篆刻的历史」动画配置对齐）：
  - `page_animation`：界面动画总开关；
  - `animation_type`：动画类型（fade 淡入 / rise 上浮 / zoom 缩放 / slide 滑入 / none 无动画）；
  - `animation_duration`：动画时长（毫秒，100–1200，默认 300）；
  - 动画在开关开启后按类型与时长生效，切换选项卡即时可见；
  - 所有动画设置修改即自动保存。
- 页面资源版本参数升至 `?v=0.17`。

## 说明

- 动画通过 CSS 变量（`--anim-name` / `--anim-duration`）驱动，前端模拟验证四种类型与开关/时长组合均正常。
- 版本备份：工作区 backup 目录下的 `astrbot_plugin_storyteller_alpha-0.17`。
