# alpha-0.38（2026-08-16）

## 变更

- **好感度 LLM 精确判断**：批量互动（15 条）后由判定模型判断关系整体变化（拉近/疏远 + 程度），
  带阻尼微调好感度；替代单纯的关键词规则，能理解语境与分寸。
- **主动对话候选可视化**：「主动」页新增候选判定记录——每次尝试展示为什么发/为什么没发
  （每日上限/刚聊完/未回应降速/沉默/发送）、用了哪些素材（心情/日程/记忆/未完话题/见闻）。
- **情绪模型再细**：状态升级为量化情绪维度（愉悦度 valence / 唤醒度 arousal / 精力 energy）
  + 自然语言标签；情绪随时间自然衰减、精力缓慢恢复；用户情绪事件即时微调维度（带节流）；
  「状态」页展示三条维度进度条。
- **日记**：每天深夜自动把当天状态变化、梦境、念头、见闻、对方情绪整理成一篇今日日记，
  「内心」页展示；形成「自我连续性」。
- **天气背景**：可手动填当前天气，影响状态演化。
- 页面资源版本参数升至 `?v=0.38`。

## 说明

- 独立实现，仅借鉴「关系演进 / 候选生命周期 / 情绪维度」等通用思路，未复刻示例插件代码
  （雷同扫描 0 处）。
- 好感度判断与日记生成只在达到阈值/深夜触发，不额外打扰主链；全部可关闭。
- 版本备份：工作区 backup 目录下的 `astrbot_plugin_storyteller_alpha-0.38`。
