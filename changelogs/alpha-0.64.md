# alpha-0.64 —— 最终信息格式注入「当前说话/上下文」+ 默认接管改换 + 各模块占位符提示卡

> 落实到用户要求的三点：
> 1. 「最终发送给对话 LLM 的信息格式」新增 `{当前说话}` 与 `{上下文}` 占位符——防抖作为模块之一，其最终决定传给对话 LLM 的内容（防抖合并结果）会注入这里，再由拦＆改统一整合发送；
> 2. 介入方式**默认改为「接管改换」**（所有开启模块注入成最终信息格式后，直连接管模型统一发送）；
> 3. 每个模块页新增「注入占位符」提示卡，标明该模块提供哪些占位符。

## 新增 / 变更

- **占位符扩展（11 个）**：`{上下文}`（该会话最近对话呼应，联动【为你篆刻的历史】时间线，最多 4 条/每条≤100 字）、`{当前说话}`（防抖合并后的对方内容）置于模板最前，其后为各模块锚。
- **接管改换注入逻辑**：`anchors["current_text"]` = 防抖最终内容（req.prompt）、`anchors["context"]` = 时间线上下文；模板已含 `{当前说话}` 时不再把原文重复作为独立 prompt（改用简短引导句），避免重复；未装载联动插件时 `{上下文}` 替换为空、不阻塞发送。
- **默认介入方式 = 接管改换**（`resolve_mode` 非法/空也回退接管改换；配置/Pfianal 状态同步）。
- **各模块「注入占位符」提示卡**：防抖（{当前说话}{上下文}）、身份（{身份}）、关系（{关系}）、风格（{风格}）、状态（{状态}{天气}）、日程（{日程}）、内心（{见闻}）、设置页记忆子模块（{记忆}）。
- 默认模板已含 `{上下文}{当前说话}`；已有用户模板需在「拦＆改」页手动补入新占位符（或保存回默认）。
