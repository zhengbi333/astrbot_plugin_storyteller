# alpha-0.130

## 时间线紧凑 + 新增「清障」选项卡 + 总览页增强

- **记忆页时间线紧凑化**（你要 1）：条目行距收紧（8px 间隙、内边距 5/6px、行高 1.45、
  去掉顶部通栏分隔线改用左色条），一屏能看更多条。
- **新增「清障」选项卡**（你要 2，位于总览之后，第 2 位）：
  - 16 项**只读模块自检**（不调 LLM、不发消息、不改数据）：配置加载 / 数据目录 /
    Token 记账 / 界面布局 / 外观 / 状态 / 日程 / 表情包图库 / 发送缓冲 / 关系档案 /
    风格·人格 / 内心世界 / 记忆联动 / 模型配置 / 后台任务 / 日志系统；
  - 每项一行：测试按钮 + 模块名 + 说明，右侧**结果块**——通过 = **绿色侧边线 + 「功能正常」**，
    异常 = **红色侧边线 + 故障原因**（存储缺失/损坏、联动未开、模型全空、后台任务不在等都会指出来）；
  - 顶部**「一键全部测试」**按钮 + 汇总（「全部通过」或「有 N 项异常：…」），单项可单独重测。
- **总览页增强**（你要 3）：新增两块展示板——
  - **Bot 当前状态**：心情标签 + 调子/转速/电量三量表 + 此刻正在做的事（日程）；
  - **Token 总消耗**：本插件（为你续写的故事）与联动记忆插件（为你篆刻的历史）各自的累计
    tokens（记忆插件未联动时显示「未联动」），详情在 Token 页。
- 新增回归 smoke_troubleshoot.py 12 项（全绿/破坏降级/异常兜底/单跑过滤/联动与模型失败分支）；
  verify_057 137 项（+9：总览 3、清障 5、导航 1）；导航 21 键（ui_state/ui/api 三处同步）。
