# alpha-0.279

## P1-10：面板显示「最近想起的记忆」

在「判定」页底部新增一块：**最近 10 轮 · 每轮命中了哪几条记忆**。

每行显示：

```
23:50:00   我下周去杭州         916 字 / 2 条
           · 关于杭州出差安排
           · 主人 11 月要去杭州
```

这样她答得不对劲时，你能立刻看出：**她是拿错了记忆，还是根本没想起相关的**。

## 接口

```
GET /astrbot_plugin_storyteller/memory/recent
```

返回 `{rounds: [...], count, total_items}`；记忆插件没装/没桥接/版本旧时，
会给出明确说明而不是空白。

## 为什么放在「判定」页

那一页已经是"可观测"主题（每个判定用哪个模型、调了几次）。
「她想起了什么」属于同一类问题，放一起不用多开一个页签。

## 验证（`audit_95_memory_recent.py` 26/26）

- **A** 底层表、三个字段、读取方法、service 一直在写、开关存在；
- **B** bridge 有 `recent_injections`、用了现成的 `recent_injection_logs`、会补摘要；
- **C** 人格插件接口：路由、处理函数、两种失败都有明确说明；
- **D** 前端：调接口、有标题、显示检索词/条目/字数条数、失败有提示；
- **E** **数据形状实测**：用假 store 跑 `recent_injections`，
  验证解析出 2 个 id、补上摘要、保留检索词与字数。

## 已知边界

- 只在 `injection.enable_injection_logs` 开着时才有数据（默认开）；
- 记忆删了以后，历史注入记录里的 id 查不到摘要，会显示 id 本身；
- 只显示最近 10 轮，不做翻页（够用来排查"刚才那句为什么答错"）。
