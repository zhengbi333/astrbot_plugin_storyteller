# alpha-0.113（主动消息：一次尝试一条 + 模板可配 + 提示词预览）

## 修改

- **一次尝试只留一条记录**：`_maybe_send` 不再预记录"生成中"（前端轮询时间短，改为生成后一次性记录终态：
  沉默 / 已发送 / 发送失败）；**不再出现"生成中 + 沉默/失败"多条**。
- **沉默/失败也保留"想要说的内容预览"**：`text` 字段存未发送的生成文本（若模型有输出），来源 chips 齐全；
  前端「未发送」字样旁仍显示内容（如截图"今天叠袜子…"这类本要发的话）。
- **主动模板可配置（`proactive.template`）**：左栏「主动模板（发给 LLM 的设定）」卡——
  textarea 编辑 + 占位符 chips（`{由头}{心情}{日程}{记忆}{未完成}{见闻}{梦}{时间}`）；
  留空 = 内置默认（两级裁决：`值不值得发→:NO:` → 自然表达）。
- **「发给主动模型 LLM 的内容」预览面板**（左栏目标用户下方）：只读展示实际发送的完整提示词
  + 生效模型 + 是否自定义模板，零 Token。后端 `GET proactive/prompt_preview`（复用 _collect_context+_build_prompt）。

## 说明

- "沉默"有**两种**：① 由头未成熟（此刻没有想说的话——由头引擎判定）；② 模型裁决 :NO:（不值得发/像打扰）——
  均记录为沉默并在 reason 区分。
- 判断机制在**主动模块内部**（由头引擎 + LLM 两级裁决），不依赖前置模块。
