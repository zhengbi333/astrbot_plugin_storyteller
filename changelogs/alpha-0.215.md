# alpha-0.215

## 25 模块深度自检 · 第 1 轮：overview 总览

### 审查结果（执行链 / 分支 / 联动 / 实测）

**执行链**：`renderOverview()` 并发拉 `presence` / `schedule` / `token/stats` 三个接口（失败静默降级），
另用启动缓存的 `health`（版本/数据目录）与 `configValues`（开关、模型配置）——总览是**纯聚合页**，没有自己的后端接口。

**实测（真实配置 + 真实数据快照）9/9 通过**：
- `presence.presence.tone/tempo/battery/mood` 路径与前端一致（真实值："夜深了有点困，想着洗漱完喝口热牛奶就还能撑住。"）
- `schedule.diagnostic.current_activity` 可达（"洗漱、热牛奶、收好明天要穿的衣服"）
- `token/stats.total.sum = 70665`（84 次调用）；`memory.total = null`（未联动）→ 页面显示"未联动"而非 0 ✅
- 关掉状态 / 日程模块后，两个接口仍返回结构、不抛异常 ✅

**空值/降级分支逐条判定**：状态不可用 → "状态数据暂不可用"；无活动 → 不渲染该行；token 缺失 → 不 NaN；
未配模型 → 顶部黄条预警；能量条按 -1..1 / 0..1 归一化（与状态页同口径）——全部 ✅。

### 发现并修复的隐患

> 状态或日程模块**关闭**后，总览仍照常展示"Bot 当前状态"与"此刻在做"，但那是**最后一次记录**（不再更新），
> 页面没有任何提示 → 用户会误以为是实时数据。

**修复**：新增 `staleNote(on)`，**只在配置明确为 `false`** 时标注"模块已关闭 · 以下是最后一次记录"
（用 `=== false` 而非 `!on`，避免配置未加载时误报）；接入状态卡片标题与"此刻在做"行。
