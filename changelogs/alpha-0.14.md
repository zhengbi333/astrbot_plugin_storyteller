# alpha-0.14（2026-08-08）

## 变更

- **修复壁纸删除后「蹦出来」**：
  - 根因：上传接口先把文件写到 `backgrounds/bg.<ext>`（如 bg.png）再由图库存为 `bg-<hash>.<ext>`，
    前者作为临时文件**永远残留**；当壁纸库删空后，旧版单图迁移逻辑发现 bg.png 存在，
    会把残留文件重新「迁移」入库——表现为删除一张又蹦出一张，反复多次；
  - 修复：
    1. 上传接口改为直接读取上传字节（不再落盘临时文件，退化路径也会即时清理）；
    2. 每次读取外观时清理 `backgrounds/` 中所有非规范命名（非 `bg-<12位hash>.png|jpg`）的文件；
    3. 迁移顺序调整为先迁移旧单图、后清理，避免清理误删待迁移文件。
- 壁纸库行为确认：同一张图重复上传自动去重（不重复占位），图库上限 5 张，超出丢弃最早一张。
- 页面资源版本参数升至 `?v=0.14`。

## 说明

- 已通过专项验证：旧残留迁移一次后删除不再蹦出；8 次上传 + 循环删除无残留；上传后目录仅含规范文件。
- 版本备份：工作区 backup 目录下的 `astrbot_plugin_storyteller_alpha-0.14`。
