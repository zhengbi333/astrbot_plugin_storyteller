# alpha-0.79 —— 轻量事件演化独立总开关（默认开，可一键彻底关闭）

> 回应「轻量演化不会是每次默认开启且无法配置吧」：轻量事件演化本质是**纯规则、不调 LLM、零成本**；
> 本次给它一个独立的「全部关闭/开启」总开关（默认开），关闭后不再写涟漪/余波、不再微调维度，
> 连情绪观察染色都归零（已有数据保留，状态只在手动一键生成或开启「自动演化」时变化）。

## 变更

- **新开关 `presence.light_evolve_enabled`（默认开）**：位于状态设置栏顶部（master-switch 卡片，紧随「状态锚总开关」语义为子级总闸）。
- **双保险闸控**：
  - `_observe_message` 情绪检测段：开关关 → 不再收集情绪缓冲、不再触发染色（节流、涟漪、余波全部归零）；
  - `_apply_emotion_impulse` 顶部防御：开关关 → 直接返回（未来任何调用方都被挡住）。
- 与「自动演化」关系不变：自动演化（节拍，唯一调 LLM 处）仍默认关；轻量演化关闭不影响手动「一键生成」与「自动演化」。
- 页面：状态页设置栏顶部新增「轻量事件演化」主开关 + 说明更新（关闭后状态只在手动/自动演化时变化）。
