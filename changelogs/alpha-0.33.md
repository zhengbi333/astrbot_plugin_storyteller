# alpha-0.33（2026-08-08）

## 变更

- **拦截移至消息入口（最上游）**：
  - 拦截器由 `on_llm_request`（主链阶段，所有插件已执行）改为**消息事件入口**（priority 2000，最先执行）；
  - 开启拦截后，消息**不会到达任何下游插件**（记忆插件等收不到），也**不会产生任何 LLM 调用**
    （stop_event + 禁止 LLM 请求标志）；
  - 命令消息放行（不拦截）；拦截记录展示消息文本（即将被发送给 LLM 的内容）与图片信息，
    因请求尚未组装，上下文字段标注「消息入口拦截，请求尚未组装」。
- **命令前缀可配置**（防抖模块新增 `command_prefixes`，默认 `/`，多个用空格/逗号分隔）：
  - 以这些前缀开头的消息识别为命令，不参与防抖合并（直接放行）；
  - **去掉「纯符号消息视为命令」的启发式**——单独打「？」「……」等不再被当作命令绕过防抖。
- **修复警告「Plugin has no changelog file」**：插件根目录新增 `CHANGELOG.md`（AstrBot 期望的文件名，
  此前仅有 `changelogs/` 目录）。
- 页面资源版本参数升至 `?v=0.33`。

## 说明

- 专项验证：命令前缀可配置（默认 /、! 等）、问号/纯符号不再是命令、入口拦截（阻断+记录）、命令放行、关闭不干预。
- 版本备份：工作区 backup 目录下的 `astrbot_plugin_storyteller_alpha-0.33`。
